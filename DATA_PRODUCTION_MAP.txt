INPUT REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════════

  1. Text2Motion Checkpoint (HyMotion)
     └─ checkpoints/HY-Motion-1.0/HY-Motion-1.0-Lite/latest.ckpt

  2. PhysFlow-trained Checkpoint (optional)
     └─ output/physflow/model_final.pt (generated by physflow_trainer.py)

  3. SMPL Human Model XML
     └─ ref_repo/OmniH2O/phc/phc/data/assets/mjcf/smpl_humanoid.xml

  4. T2M Config
     └─ configs/hymotion_t2m/hymotion_t2m_201dim_046b.py

  5. Text Embeddings (optional, pre-computed)
     └─ output/physflow/text_embeddings.pt (from physflow_precompute_text.py)


MAIN ENTRY POINT - physflow_eval_and_export.py
═══════════════════════════════════════════════════════════════════════════════

  INPUT (models + curriculum)
       ↓
       ├─ Loads: physflow_curriculum.PHYSFLOW_LEVELS (8 difficulty levels, 40+ prompts)
       ├─ Loads: Original T2M model (HyMotion checkpoint)
       ├─ Loads: PhysFlow-trained model (optional, model_final.pt)
       └─ Loads: Physics oracle (physflow_physics_oracle.py + run_smpl_physics_sim.py)
            ↓
       ┌─────────────────────────────────────────────┐
       │  EVALUATION LOOP                            │
       │  for each curriculum prompt:                │
       │    1. Generate motion_135 (original model)  │
       │    2. Generate motion_135 (trained model)   │
       │    3. Physics-correct both                  │
       │    4. Compute metrics                       │
       │    5. Export all formats                    │
       └─────────────────────────────────────────────┘
            ↓
       ┌─────────────────────────────────────────────────────────────┐
       │ EXPORT FUNCTIONS                                            │
       ├─ save_motion():           NPZ + SMPL mesh JSON + metadata   │
       ├─ save_physics_motion():   SMPL mesh JSON (physics variant)  │
       └─ metrics.json:            Summary comparison table          │
       └─────────────────────────────────────────────────────────────┘
            ↓
       OUTPUT DIRECTORY: output/physflow/eval_demo/

DATA FLOW: physflow_eval_and_export.py → eval_demo/ structure
═══════════════════════════════════════════════════════════════════════════════

  [CURRICULUM PROMPTS]
        ↓
  [T2M MODEL GENERATION]
        ├─ generate(prompt, num_frames)
        └─ motion_135: (T, 135) [transl(3) + 22*rot6d(132)]
             ↓
  [PHYSICS ORACLE CORRECTION]
        ├─ oracle.correct(motion_135)
        └─ motion_135_phys: (T, 135) [corrected by MuJoCo sim]
             ↓
  [METRICS COMPUTATION]
        ├─ completion_rate, tracking_error, jerk, gen_time
        └─ stored in per-motion metadata
             ↓
  [EXPORT FUNCTIONS]
        ├─ save_motion() → data/npz/ + data/smpl_mesh/ + data/meta/
        ├─ save_physics_motion() → data/smpl_mesh_physics/
        └─ metrics.json (summary)
             ↓
  [OPTIONAL: ROBOT RETARGETING]
        ├─ pipeline_motion_to_robot.py
        ├─ motion_135_to_pyroki_keypoints.py
        └─ data/robot_motion/ + batch_retarget*.sh

SUMMARY STATISTICS
═══════════════════════════════════════════════════════════════════════════════

Quick Mode (default for demo):
  • Total motions: 12 (6 original + 6 physflow)
  • Prompts per level: 2 (from levels 0-2)
  • Output files:
    - NPZ files: 12
    - SMPL mesh JSON: 12 (kinematic) + 12 (physics) = 24
    - Metadata JSON: 12
    - Total JSON size: ~30-50MB
    - Total NPZ size: ~5-10MB
  • Time: ~2-5 hours (depends on GPU)

Full Mode:
  • Total motions: 40-50 (across 8 curriculum levels)
  • Output files: proportionally larger
  • Time: ~8-12 hours

Robot Retargeting (optional):
  • Time per motion: ~60 min (CPU, PyRoki)
  • Parallel workers: configurable
  • Total for 12 motions: ~2-3 hours (with 8 workers)
