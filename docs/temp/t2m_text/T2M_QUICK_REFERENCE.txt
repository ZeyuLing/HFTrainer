📊 TEXT EMBEDDINGS SUMMARY

Dimension Reference:
  - vtxt (sentence vector):    (B, 1, 768)    [CLIP-L, L2-normalized]
  - ctxt (token embeddings):   (B, 128, 4096) [Qwen3, NOT normalized]
  - ctxt_length:               (B,)           [actual pre-padding length]

Null Embeddings (for CFG):
  - null_vtxt_feat:   nn.Parameter (1, 1, 768)   [zero-initialized]
  - null_ctxt_input:  nn.Parameter (1, 1, 4096)  [zero-initialized]

═══════════════════════════════════════════════════════════════════════════════
🔄 TEXT CONDITIONING - 3 PATHS

Path 1: Pre-Encoded Text (FASTEST)
  → Batch contains: text_vec_raw, text_ctxt_raw, text_ctxt_raw_length
  → Direct use, no encoding needed

Path 2: Online Caption Encoding
  → Batch contains: caption field
  → Call bundle.encode_text(captions)
  → Returns: {text_vec_raw, text_ctxt_raw, text_ctxt_raw_length}

Path 3: Null Embeddings (UNCONDITIONAL)
  → When caption is empty or zero-length
  → Use bundle.null_vtxt_feat and bundle.null_ctxt_input

═══════════════════════════════════════════════════════════════════════════════
✅ CFG DROPOUT - Bernoulli Masking

Implementation:
  1. Generate per-batch mask: Bernoulli(p=cond_mask_prob)  [default: 0.1]
  2. Where mask=1, replace text embeddings with null embeddings
  3. This makes ~10% of batch unconditional

Code:
  mask = torch.bernoulli(torch.ones(bs, device=device) * cond_mask_prob)
  vtxt_masked = where(mask, null_vtxt_feat.expand_as(vtxt), vtxt)
  ctxt_masked = where(mask, null_ctxt_input.expand_as(ctxt), ctxt)

🔍 TEXT NORMALIZATION

CLIP-L (vtxt):
  ✅ L2-normalized to unit vector
  Location: text_encoder.py line 254
  Output magnitude: ≈ 1.0

Qwen3 (ctxt):
  ❌ NOT normalized (raw hidden state)
  Output magnitude: arbitrary, depends on LLM output scale

═══════════════════════════════════════════════════════════════════════════════
⚙️ TEXT PADDING CONVENTION

Default: max_text_len = 128

Process:
  1. Encode text → ctxt (B, Lc, 4096) where Lc is actual token count
  2. Store ctxt_length = Lc (pre-padding)
  3. Pad or truncate ctxt to 128: F.pad(ctxt, (0,0,0,pad_len-Lc))
  4. Build padding_mask: [True]*Lc + [False]*(128-Lc)
  5. Pass mask to transformer for attention masking

🆚 T2M vs M2M DIFFERENCES

Text Processing: IDENTICAL
  ✅ Both use Qwen3-8B + CLIP-L
  ✅ Both apply CFG dropout with Bernoulli masking
  ✅ Both have null embeddings as nn.Parameters
  ✅ Both pad to max_text_len=128

Motion Processing: KEY DIFFERENCE
  ❌ M2M: 135-dim (absolute transl + rot6d)
  ❌ T2M: 201-dim (relative transl + rot6d for 33-joint SMPL)

Model Input: KEY DIFFERENCE
  ❌ M2M: x_input = [x_t + VACE_context] = (B,L,540)
  ❌ T2M: x_input = x_t only = (B,L,201)
