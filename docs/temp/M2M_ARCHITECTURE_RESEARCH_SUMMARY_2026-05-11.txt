KEY FINDINGS
================================================================================

1. TEXT CONDITIONING SYSTEM
───────────────────────────
✓ Encoder: HYTextModel (Qwen3-8B + T5-XXL fusion)
✓ Outputs: 
  - vtxt (B, 1, 768): Sentence-level CLIP embedding
  - ctxt (B, 128, 4096): Token-level T5-XXL embeddings
✓ Device: CPU (never GPU) — each DDP rank has own copy
✓ CFG: Bernoulli masking replaces text with null embeddings (100% during training)

CRITICAL BUG (2026-03-27): ✅ FIXED
  Problem: Null embeddings saved/loaded as all-zeros
  Symptom: Inference ODE divergence (random null conditioning)
  Cause: Bundle-level Parameters not in state_dict_to_save()
  Fix: '__bundle_params__' key + DDP gradient sync + Accelerator checkpoint adapter
  Status: Fully resolved (commit 9a67a3d)

2. MOTION CONDITIONING (VACE)
──────────────────────────────
Three Modes Implemented:
  a) split_reactive (default v2): [inactive, reactive, mask] → 3*D context
  b) clean_zero_mask: [inactive, zeros, mask] → 3*D (unused)
  c) no_inactive (v2 slim): [reactive, mask] → 2*D (optimized for MAN)

Current Best: no_inactive + MAN training
  - Rationale: With MAN, x_t[known] already contains clean motion
  - Saves 1/3 context dimension; same quality
  - Used in production models

Input Composition:
  x_input = [x_t | vace_context] = (B, L, 540) for 135-dim motion with split_reactive

3. FLOW MATCHING & TRAINING
────────────────────────────
Forward Process: x_t = (1-t)*x0 + t*x1, t ∈ [0,1]
  - x0: Gaussian noise
  - x1: Target clean motion
  - t: Uniform or biased toward high-t sampling

Mask-Aware Noise (MAN): ✅ ENABLED BY DEFAULT
  - x_t[known] = x1 (clean): enforces distribution match with inference
  - x_t[generate] = noisy: regions to predict
  - Controlled by: mask_aware_noise=True + src_mask in batch

Prediction: Two modes
  1. velocity (default): predict v = x1 - x0
  2. x1: predict target directly (experimental)

Loss: smooth_l1(pred_velocity, gt_velocity) + FK losses + smoothness
  - Generation mask focuses loss on masked regions only
  - FK losses (keypoints3d_weight) require body_model

4. DENOISER ARCHITECTURE (HunyuanMotionMMDiT)
──────────────────────────────────────────────
Structure:
  Input → Double-Stream Blocks (1/3) → Single-Stream Blocks (2/3) → Output

Double-Stream (Early):
  - Motion and text in parallel streams
  - Motion ↔ Text cross-attention
  - Modality-specific MLP weights
  - For: Rich modality-specific features

Single-Stream (Late):
  - [motion, text] concatenated
  - Shared MLP weights
  - More efficient; global motion-text fusion
  - For: High-level semantic integration

Attention Masks:
  - Full (default): All tokens attend to all
  - Causal: Token i → positions ≤ i (autoregressive)
  - Narrowband: Local window (30fps * narrowband_length frames)

Adapter: timestep_feat + vtxt_feat (+ CDE if CRFM v3)
  - Broadcast to all sequence positions
  - Modulates all transformer blocks via ModulateDiT

5. MOTION REPRESENTATION
─────────────────────────
135-dim (SMPL-22):
  [0:3]    Translation (absolute global)
  [3:9]    Root rotation (6D representation)
  [9:135]  Body rotations (21 joints × 6D)

198-dim (Extended):
  [0:135]  As above
  [135:198] Joint positions (21 × 3D), Scheme D: XZ_rel + Y_abs

rot6d Format:
  - First 2 rows of 3×3 rotation matrix
  - Orthonormal via Gram-Schmidt during FK
  - Used for numerical stability

7. PIPELINE INFERENCE
──────────────────────
Replacement Guidance (for _man models):
  - "none": Standard ODE from noise → clean (non-MAN)
  - "all": Replace known regions every ODE step
  - "skip_last": Replace every step except final (RECOMMENDED for _man)
  - "flow_interp": Experimental flow-based (unused)

SDEdit Support: sdedit_tau ∈ [0,1]
  - τ=0: Full regeneration (standard)
  - τ=1: Pure imputation (no change)
  - Use: Motion repair tasks (E9) for subtle defect cleanup

8. MODEL VARIANTS & EXTENSIONS

ARCHITECTURE FLOW DIAGRAM
================================================================================

TRAINING:
─────────
Batch → Normalize(motion) → Sample t, x_t
    ↓
Text: encode or load pre-extracted
    ↓
CFG: bernoulli masking (100%)
    ↓
VACE: prepare_vace_input([src_motion, src_mask])
    ↓
MMDiT: forward(x_t + vace, ctxt, vtxt, t)
    ↓
Loss: smooth_l1(pred_vel, gt_vel) [masked, with FK losses]
    ↓
Backward → Update parameters


INFERENCE:
──────────
Caption (optional) → encode_text() on CPU
    ↓
src_motion, src_mask → prepare_vace_input()
    ↓
ODE Loop (t: 1 → 0):
  ├─ VACE: prepare_vace_input()
  ├─ MMDiT forward
  ├─ ODE step
  └─ Replace known regions (if replacement_guidance ≠ 'none')
    ↓
Denormalize + FK → 3D keypoints
    ↓
Output: (B, L, 22, 3) or NPZ format

CONFIGURATION RECOMMENDATIONS
================================================================================

FOR NEW MODELS:
  ✓ Use mask_aware_noise=True (training efficiency + inference consistency)
  ✓ Use vace_condition_mode='no_inactive' (saves 1/3 parameter)
  ✓ Use replacement_guidance='skip_last' (matches MAN distribution)
  ✓ Use pred_type='velocity' (not x1)

FOR CHECKPOINT LOADING:
  ✓ Always use load_scope='full' for M2M (preserves null embeddings)
  ✓ Verify null_vtxt_feat/null_ctxt_input shape match text dims
  ✓ Test inference immediately after loading (ODE should be smooth)

FOR TEXT CONDITIONING:
  ✓ Pre-extract embeddings when possible (CPU text_encoder bottleneck)
  ✓ Keep max_text_len=128 (gradient + attention mask consistency)
  ✓ Verify CFG masking during training (cond_mask_prob=1.0 recommended)

FOR INFERENCE:
  ✓ num_steps ≥ 30 (quality plateaus beyond 50)
  ✓ text_guidance_scale ∈ [5.0, 10.0] (7.5 typical)
  ✓ For _man models: always use replacement_guidance='skip_last'
