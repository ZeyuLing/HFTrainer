## 3. SMOOTH ROOT POSITION COMPUTATION

File: ref_repo/KIMODO/kimodo/kimodo/motion_rep/smooth_root.py
Function: get_smooth_root_pos(hip_translations) [lines 201-234]

Algorithm:
  1. Input: [B, T, 3] raw root translations
  2. Split: X-Z plane vs Y (height) separately
  3. Smooth X-Z with ADMM-based TrajectorySmoother
     - Margin constraint: 0.06 meters (line 216)
     - Multigrid approach: coarse-to-fine (smooth_signal function)
     - 100+ ADMM iterations (default)
  4. Preserve Y unchanged
  5. Output: [B, T, 3] smoothed positions

Key constraint: keeps ground plane motion smooth, preserves vertical motion exactly.


## 4. ROOT HEADING EXTRACTION

File: ref_repo/KIMODO/kimodo/kimodo/motion_rep/feature_utils.py
Function: compute_heading_angle(posed_joints, skeleton) [lines 111-126]

Computation:
  r_hip, l_hip = skeleton.hip_joint_idx  # [right_hip_idx, left_hip_idx]
  diff = posed_joints[:, :, r_hip] - posed_joints[:, :, l_hip]
  heading_angle = torch.atan2(diff[..., 2], -diff[..., 0])
  
Where:
  - posed_joints shape: [B, T, J, 3] (global joint positions)
  - Returns: [B, T] angles in radians
  
Encoding (line 81, kimodo_motionrep.py):
  global_root_heading = torch.stack([cos(angle), sin(angle)], dim=-1)  # 2-dim vector
