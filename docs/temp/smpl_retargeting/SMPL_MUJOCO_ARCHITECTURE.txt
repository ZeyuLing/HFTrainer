SPEC SHEET
──────────
Humanoid Type:          SMPL (22-joint + root) / SMPL-X (with hands)
Bodies:                 23 (1 pelvis + 22 joints)
DOF:                    ~69 (7 free root + 66 hinge angles)
Collision:              Capsules (limbs) + Boxes (feet/hands/head)
Control:                Proportional-Derivative (PD)
Simulation Rate:        120 FPS (decimation 4 = 30 Hz control)
Motion Format:          motion_135 (rot6d) → SMPL-X axis-angle
Data Conversion:        Implemented (motion135_to_smplx.py)
Physics Backend:        MuJoCo (via Newton simulator)
GPU Support:            ✅ IsaacGym, IsaacLab, Genesis
CPU Support:            ✅ Newton, Genesis

GOTCHAS & TIPS
──────────────
1. Rot6D Layout: HyMotion uses row-major [R00,R01,R10,R11,R20,R21]
                 Reorder [0,2,4,1,3,5] before Gram-Schmidt
2. Joint Order: Free root (7) + L_Hip(3) + L_Knee(3) + ... (60+)
3. Stability: Use stiffness=1000 for torso, damping=80-100
4. Contact: Condim=3 enables friction; margin=0.001 for stability
5. Hand Control: motion_135 is 22-joint SMPL (no hands)
                 Use SMPL-X config for detailed hand simulation
