🎯 t² TIMESTEP WEIGHTING (CRITICAL):
───────────────────────────────────────────────────────────────────────────────

WHERE:   Applied to ALL three KIMODO auxiliary losses
         ✓ aux_joint_pos
         ✓ aux_joint_vel
         ✓ aux_fk_consistency

HOW:     t_sq = timesteps ** 2
         loss_weighted = loss_base * t_sq

EFFECT:  • t=0 (pure noise):   loss ≈ 0 (no signal to supervise)
         • t=1 (clean data):   loss = full weight
         • E[t²] = 1/3         average impact is 1/3 of nominal weight

RATIONALE: FK on pure noise is uninformative. Down-weight supervision
           when prediction is mostly noise.
