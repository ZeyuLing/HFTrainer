1. Text input → CLIP-L + Qwen3 encoders
2. Prepare batch pairs:
   ├─ Unconditional: null_vtxt (1×768) + null_ctxt (seq×4096)
   └─ Conditional: real_vtxt (1×768) + real_ctxt (seq×4096)
