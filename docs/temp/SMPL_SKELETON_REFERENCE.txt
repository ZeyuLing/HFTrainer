Standard SMPL convention (verify with FK output):
  X-axis: Left-Right   (negative=left, positive=right)
  Y-axis: Up-Down      (negative=down, positive=up)     <-- HEIGHT AXIS
  Z-axis: Forward-Back (negative=back, positive=forward)

  FOOT (joint 10/11):   [±0.1, 0.0, 0.0]  ← Bottom (Y=0.0)

Height = max(Y) - min(Y) = 1.65 - 0.0 = 1.65 meters

================================================================================
HEIGHT ESTIMATION FORMULA
================================================================================

METHOD: Forward Kinematics (FK) + Direct Measurement

INPUTS:
  smplx_output.joints  ← numpy array of shape (T, 22, 3)
                         T = number of frames
                         22 = number of joints
                         3 = xyz coordinates

CODE:
  joints = smplx_output.joints.detach().numpy()  # (T, 22, 3)
  
  head_positions = joints[:, 15, :]  # All frames, head joint
  left_foot_positions = joints[:, 10, :]
  right_foot_positions = joints[:, 11, :]
  
  # Y-axis is vertical (index 1)
  head_y_max = head_positions[:, 1].max()
  foot_y_min = min(left_foot_positions[:, 1].min(), 
                   right_foot_positions[:, 1].min())
  
  human_height = head_y_max - foot_y_min

VALIDATION:
  if 1.3 <= human_height <= 2.3:
      return human_height
  else:
      return 1.7  # Fallback to average

================================================================================
VALIDATION CHECKLIST
================================================================================

When testing height estimation:

[ ] FK output shape is (T, 22, 3)
[ ] All coordinates are finite (no NaN or Inf)
[ ] Head Y-coordinate > Foot Y-coordinate
[ ] Height difference > 1.0 (not flat)
[ ] Height < 3.0 (not explosion)
[ ] Same input produces same output (deterministic)
[ ] Different motions produce different heights (variance)

Debug output to check:
