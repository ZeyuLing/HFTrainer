  │                                                                  │
  │ For each batch:                                                 │
  │   1. Sample captions from data                                  │
  │   2. Encode with lazy-loaded text encoder (CLIP-L + Qwen3)      │

  │   4. Randomly mask 10% (cond_mask_prob=0.1):                    │

  │   6. Compute loss (FK loss + velocity loss + smoothness)        │
  │   7. Backprop gradient through RANDOM text layers               │
  │      ├─ Gradient tells: "these random projections are WRONG"    │
  │      ├─ Gradient tells: "text_refiner should map text → signal" │
  │      └─ Weights update toward USEFUL values                    │
  │   8. Optimizer step                                             │
  │                                                                  │
  │ EPOCH 0→1: Text layers converge from RANDOM → USEFUL            │
  │ EPOCH 1→N: Text layers continue refining, converge to optimum   │
  └─────────────────────────────────────────────────────────────────┘


THREE SAFEGUARDS AGAINST "GARBAGE OUTPUT"
──────────────────────────────────────────

  SAFEGUARD 1: Null Embedding Source Fallback
  ┌─────────────────────────────────────────────────────────────────┐
  │ Even if null embeddings are RANDOM after loading, they get      │
  │ patched from HY-Motion-1.0 pretrained. CFG inference will see   │
  │ VALID null embeddings, not garbage.                             │
  │                                                                  │
  │ CFG equation: pred = pred_uncond + scale * (pred_cond - uncond)│
  │                    ✅ valid         ✅ random→trained           │
  │                                                                  │
  │ RISK WITHOUT THIS: CFG would amplify garbage nulls → explodes   │
  └─────────────────────────────────────────────────────────────────┘

  SAFEGUARD 2: CFG Training (10% unconditional batches)
  ┌─────────────────────────────────────────────────────────────────┐
  │ 10% of training batches use ONLY null embeddings. Model learns  │
  │ to generate reasonable motion even without real text. This      │
  │ trains the "unconditional path" properly.                       │
  │                                                                  │
  │ RESULT: null embeddings get gradient updates → converge to      │
  │ useful values beyond just "from T2M pretrained"                 │
  └─────────────────────────────────────────────────────────────────┘

  SAFEGUARD 3: Training Loss Supervision
  ┌─────────────────────────────────────────────────────────────────┐
  │ RANDOM text layers produce WRONG predictions initially:         │
  │   pred_random = random_text_refiner(text)  → Garbage signal     │
  │   pred_cross_attn = garbage_proj(garbage_signal)  → Wrong       │
  │                                                                  │
  │ BUT: Loss is computed against GROUND TRUTH motion               │
  │   loss = MSE(pred_wrong, gt_motion)  → LARGE                    │
  │   gradient = ∂loss/∂random_weights  → Tells model to improve    │
  │   weights ← weights + lr * gradient  → Moves toward GOOD values │
  │                                                                  │
  │ After 1-2 epochs: random layers have converged far from random  │
  │ RESULT: Text layers now actually USEFUL                         │
  └─────────────────────────────────────────────────────────────────┘

ANSWER TO ORIGINAL 5 QUESTIONS
───────────────────────────────

1. CHECKPOINT LOADING LOGIC
   ├─ Phase 1: AccelerateRunner._pre_prepare_load() (pre-FSDP)
   ├─ Phase 1B: _patch_zero_null_embeddings_from_pretrained()
   ├─ Phase 2: AccelerateRunner._handle_load() (post-FSDP)
   └─ Entry: BaseModelBundle.load_state_dict_selective(strict=False)

2. TEXT-RELATED LAYERS INIT
   ├─ Cross-attention: RANDOMLY INITIALIZED (not in uncond ckpt)
   ├─ Text refiner: RANDOMLY INITIALIZED (not in uncond ckpt)
   ├─ null_vtxt_feat: PATCHED from HY-Motion-1.0 (via fallback)
   ├─ null_ctxt_input: PATCHED from HY-Motion-1.0 (via fallback)
   └─ Text encoder: LAZY-LOADED fresh on first use

3. IF SOURCE LACKS TEXT LAYERS
   ├─ Missing keys logged as warnings (strict=False prevents error)
   ├─ Layers stay randomly initialized
   ├─ Training trains them from random → convergence
   └─ No model crash, just slower convergence initially

4. STRICT=FALSE MECHANISM
   ├─ Returns (missing_keys, unexpected_keys) instead of raising
   ├─ Allows partial loading of state dicts
   ├─ Shape mismatches filtered gracefully (lines 744-760)
   ├─ Bundle orphan params restored from __bundle_params__
   └─ Training proceeds even with missing text layers

5. NULL_EMBEDDING_SOURCE FALLBACK
   ├─ After model load, detects if null embeddings are zero
   ├─ Loads from: null_embedding_source config or T2M pretrained
   ├─ Patches: null_vtxt_feat, null_ctxt_input with valid values
   ├─ Ensures: CFG inference always sees valid unconditional signal
   └─ Prevents: Garbage output from random null embeddings
