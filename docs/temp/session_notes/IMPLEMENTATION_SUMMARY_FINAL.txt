OBJECTIVE
================================================================================

Eliminate text signal dilution in PRISM model by implementing encoder_hidden_states_mask 
support across training and inference pipelines.

Root Problem:
- Text embeddings padded to max_sequence_length=256 tokens
- Real prompts ~7 tokens → 249/256 padding (97.3%)
- Transformer attended equally to valid tokens AND padding noise
- Text signal diluted by 98.4%

Solution:
- Create binary attention masks for text tokens
- Pass masks to transformer to exclude padding from attention
- Increase effective attention from 0.39% to 14.3% for typical prompts

def encode_prompt_with_mask(prompt, max_sequence_length, prompt_drop_rate, dtype):
    # Tokenize, encode, and create attention mask
    seq_lens = compute_actual_token_lengths(tokenizer_mask)
    encoder_hidden_states_mask = torch.zeros(B, max_sequence_length)
    for i, seq_len in enumerate(seq_lens):
        encoder_hidden_states_mask[i, :seq_len] = 1  # Mark valid tokens
    return prompt_embeds, encoder_hidden_states_mask

DATA FLOW BEFORE & AFTER
================================================================================

BEFORE (Broken):
  Text: "a person walks" (7 tokens)
       ↓ Tokenize + pad to 256
  Tokens: [CLS, a, person, walks, [PAD], ..., [PAD]] (7 + 249 padding)
       ↓ Encode
  Embeddings: [1, 256, 768] (7 real + 249 zero-padding)
       ↓ Transformer
  Attention: 256 positions equally attend
       → 1/256 = 0.39% to each real token
       → 249 * 0.39% = 97% attention wasted on padding

AFTER (Fixed):
  Text: "a person walks" (7 tokens)
       ↓ Tokenize + pad to 256
  Tokens: [CLS, a, person, walks, [PAD], ..., [PAD]]
  Mask:   [1, 1, 1, 1, 0, ..., 0]  ← Created!
       ↓ Encode
  Embeddings: [1, 256, 768]
  Mask:       [1, 256] (1 for valid, 0 for padding)
       ↓ Transformer
  Attention: Only 7 positions attend (masked padding out)
       → 1/7 = 14.3% to each real token
       → 100% attention on real text ✓

Signal Quality Improvement:
  Before: 0.39% effective attention
  After:  14.3% effective attention
  Improvement: 37x better signal-to-noise ratio
