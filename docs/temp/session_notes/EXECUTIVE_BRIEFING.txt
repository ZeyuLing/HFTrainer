CRITICAL ERROR SUMMARY:

  ✗ Frame Conversion Incomplete
    └─ IK solver runs in mixed SMPL-X (Y-up) / MuJoCo (Z-up) frame
    └─ Post-hoc conversion doesn't fix underlying IK error
    └─ Fix: Apply frame conversion BEFORE IK, not after

  ✗ Joint Mapping Under-Constrained  
    └─ G1 hip has 3 DOF: pitch, roll, yaw
    └─ Only hip_roll_link explicitly mapped in IK config
    └─ Hip pitch/yaw left to IK solver inference
    └─ Fix: Add explicit constraints for all 3 hip DOFs + ankle_roll

  ✗ IK Solver Poorly Tuned
    └─ Damping 0.5 (HIGH) → kills joint velocity
    └─ Max iterations 10 (LOW) → insufficient convergence
    └─ No error normalization by body scale
    └─ Fix: damping 0.5→0.1, max_iter 10→30, add error normalization

  ✗ FK Ground Correction Per-Frame
    └─ Each frame's root height independently adjusted
    └─ Root height jumps between frames → trembling motion
    └─ Fix: Use smooth mode with median offset, verify post-correction

  ✗ Velocity Computation Naive
    └─ Savitzky-Golay window too small (9 frames)
    └─ Boundary ramping suppresses motion at sequence start/end
    └─ Angular velocity computed from raw quaternion differences
    └─ Fix: Larger window (13-15), remove ramp, smooth quat before deriv
