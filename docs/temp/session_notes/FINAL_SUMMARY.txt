3. NPZ INPUT FORMAT (motion_135)
================================================================================

FILE STRUCTURE:
───────────────
.npz contains:
  - motion_135: np.ndarray shape (T, 135), dtype float32
  - fps: int (typically 30)
  - prompt: str (motion description, e.g., "a_person_stands_still")

PAYLOAD BREAKDOWN (135 values per frame):
──────────────────────────────────────────
[0:3]     Translation (3 values):     [tx, ty, tz] — root position
[3:135]   Rot6D (132 values):         22 joints × 6 values each

ROT6D FORMAT PER JOINT (row-major):
────────────────────────────────────
Input:  [R00, R01, R10, R11, R20, R21]
Reorder:[R00, R10, R20, R01, R11, R21] (column-major for Gram-Schmidt)
Meaning: First two columns of 3×3 rotation matrix
Output:  Complete 3×3 rotation matrix (after orthogonalization)
Final:   Axis-angle [rx, ry, rz]

JOINT STRUCTURE (22 joints):
─────────────────────────────
Joint 0:  Pelvis (root)
Joints 1-21: Body joints
  - L_Hip (1), R_Hip (2), L_Knee (4), R_Knee (5)
  - L_Ankle (7), R_Ankle (8), L_Foot (10), R_Foot (11)
  - Spine chain: Spine1 (3), Spine2 (6), Spine3 (9)
  - Neck (12), L_Collar (13), R_Collar (14), Head (15)
  - L_Shoulder (16), R_Shoulder (17), L_Elbow (18), R_Elbow (19)
  - L_Wrist (20), R_Wrist (21)

4. SMPL MESH JSON OUTPUT FORMAT
================================================================================

COMPLETE SCHEMA:
────────────────
{
  "type": "frames",                    // Always "frames"
  "fps": 30,                           // Playback framerate
  "frames": [                          // Array of T frames
    [                                  // Frame 0 (1-element array = 1 person)
      {
        "id": 0,                       // Person ID
        "gender": "neutral",           // SMPL gender
        "smpl_type": "smplh",          // Model type (24, 52, or 55 joints)
        "Rh": [[rx, ry, rz]],         // Root orientation (axis-angle, 2D wrapped)
        "Th": [[tx, ty, tz]],         // Root translation (2D wrapped)
        "poses": [[p0, p1, ..., pN]], // Flattened axis-angles for ALL joints (2D wrapped)
        "shapes": [[0.0]*16],         // Shape coefficients (always 16 zeros)
        "mocap_framerate": 30         // Frame rate (copy of fps)
      }
    ],
    [                                  // Frame 1
      { ... }
    ],
    ...
  ]
}

POSES ARRAY SIZE BY SMPL TYPE:
───────────────────────────────
SMPL:    72 dims  = root(3) + body joints(69)
SMPL+H:  156 dims = root(3) + body joints(63) + hands(90)
SMPL-X:  165 dims = root(3) + body joints(63) + jaw(3) + eyes(6) + hands(90)

motion_135 MAPPING:
────────────────────
Provides 22 joints → 66 active dimensions
Remaining dimensions: zero-filled to match SMPL type
Example for SMPL+H (156 dims):
  [root(3) | body(63) | hands(90)]
   active   active    zeros

7. CONVERSION ALGORITHM (Step-by-Step)
================================================================================

STEP 1: LOAD NPZ
─────────────────
data = np.load(npz_path, allow_pickle=True)
motion_135 = data['motion_135']        # (T, 135)
fps = int(data['fps'])                 # 30
T = motion_135.shape[0]                # number of frames

STEP 2: EXTRACT COMPONENTS
───────────────────────────
transl = motion_135[:, :3]             # (T, 3)
rot6d = motion_135[:, 3:].reshape(T, 22, 6)  # (T, 22, 6)

STEP 3: CONVERT ROTATIONS (rot6d → axis-angle)
────────────────────────────────────────────────
a) Reorder indices [0,2,4,1,3,5] from row-major to column-major
b) Extract first column: a1 = rot6d[:, :3]
c) Extract second column: a2 = rot6d[:, 3:6]
d) Gram-Schmidt orthogonalization:
   b1 = a1 / ||a1||
   b2 = (a2 - (b1·a2)b1) / ||...||
   b3 = b1 × b2 (cross product)
e) Stack into 3×3 rotation matrix and convert to axis-angle
Result: axis_angle shape (T, 22, 3)

STEP 4: DECOMPOSE POSES
────────────────────────
root_orient = axis_angle[:, 0, :]        # (T, 3)
body_pose = axis_angle[:, 1:22, :]       # (T, 21, 3)

STEP 5: BUILD SMPL POSES (example: SMPL+H)
─────────────────────────────────────────────
poses_per_frame = np.zeros((T, 156), dtype=np.float32)
poses_per_frame[:, :3] = root_orient           # root
poses_per_frame[:, 3:66] = body_pose.reshape(T, 63)  # body
# Remaining dims (66:156) stay zero (hands)

STEP 6: BUILD JSON FRAMES
──────────────────────────
frames = []
for t in range(T):
    frame = [{
        "id": 0,
        "gender": "neutral",
        "smpl_type": "smplh",
        "Rh": [root_orient[t].tolist()],
        "Th": [transl[t].tolist()],
        "poses": [poses_per_frame[t].tolist()],
        "shapes": [[0.0] * 16],
        "mocap_framerate": fps,
    }]
    frames.append(frame)

STEP 7: BUILD OUTPUT JSON
──────────────────────────
result = {
    "type": "frames",
    "fps": fps,
    "frames": frames,
}

STEP 8: SAVE JSON (COMPACT FORMAT)
────────────────────────────────────
with open(json_path, 'w') as f:
    json.dump(result, f, separators=(',', ':'))
File size: ~425 KB for 120 frames @ 30fps
