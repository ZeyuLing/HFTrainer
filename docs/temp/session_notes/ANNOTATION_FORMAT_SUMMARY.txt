KEY FINDINGS - EXACT FIELD NAMES AND STRUCTURE
================================================================================

MAIN ANNOTATION FILE (train_hymotion_400h.json):
{
    "meta_info": {
        "dataset": string,
        "version": string
    },
    "data_list": {
        "entry_key_1": {
            // REQUIRED MOTION FIELDS
            "smplx_path": string or list,       // Motion file path (can be list for multi-person)
            "num_frames": integer,              // Total frames
            "fps": float,                       // Frames per second
            "duration": float,                  // Duration in seconds
            "has_hand": boolean,                // Hand motion included?
            "subset": string,                   // Data subset name
            
            // CAPTION (at least one REQUIRED)
            "hierarchical_caption_path": string,  // ← PREFERRED
            "caption_path": string,              // ← FALLBACK 1
            "caption": string or list,           // ← FALLBACK 2
            
            // OPTIONAL AUDIO/MUSIC
            "music_path": string,
            "genre": string,
            "audio_path": string,
            "sr": integer,
            
            // OPTIONAL SPEECH
            "speech_script_path": string,
            "speaker_id": string,
            
            // OPTIONAL METADATA
            "language": string
        }
    }
}

HIERARCHICAL CAPTION FILE FORMATS:

Format 1 - HyMotion (RECOMMENDED):
{
    "result": [
        {
            "short_caption": string,                    // Main caption
            "short_caption_rewritten": [string, ...]   // Augmented variants (OPTIONAL)
        }
    ]
}

Format 2 - Legacy Hierarchical:
{
    "macro": [string, ...],     // Coarse descriptions
    "meso": [string, ...],      // Medium descriptions
    "micro": [string, ...]      // Fine descriptions
}

================================================================================
DATASET LOADING CODE LOCATIONS
================================================================================

1. Base Dataset Loader:
   hftrainer/datasets/motion/motionhub/single_agent_dataset.py
   - load_data_list(): Parses main JSON

2. Main Dataset Class:
   hftrainer/datasets/motion/motionhub/multitask_multiagent_dataset.py
   - prepare_data(): Builds sample with resolved paths
   - Uses hierarchical_caption_path → caption_path precedence

3. Caption Loading Transforms:
   hftrainer/datasets/motion/motionhub/transforms/load_text.py
   - LoadHierarchicalCaption: For legacy format (macro/meso/micro)
   - LoadHYMotionCaption: For HyMotion format (result array)
   - LoadCompatibleCaption: AUTO-DETECTS both formats
   - LoadPreExtractedTextEmbedding: Loads pre-computed embeddings

================================================================================
CRITICAL IMPLEMENTATION DETAILS
================================================================================

1. DATA_LIST IS A DICTIONARY, NOT AN ARRAY
   - Keys are unique identifiers
   - Iteration: for data in data_list.values()

2. CAPTION FIELD PRECEDENCE
   Check in order: hierarchical_caption_path → caption_path → caption

3. CAPTION FORMAT AUTO-DETECTION
   - If "result" key exists → HyMotion format
   - Else if "macro", "meso", "micro" all exist → Legacy format
   - Else → Error

4. CAPTION EXTRACTION
   HyMotion:
   - Try short_caption_rewritten first (list of variants)
   - Fallback to short_caption (single string)
   - Accepts both "short_caption" and "short caption" (underscore/space)

   Legacy:
   - Flatten all macro/meso/micro captions
   - Track granularity label for each
   - Return both caption and granularity on selection

5. PRE-EXTRACTED EMBEDDINGS
   - Caption path maps to embedding .pt file
   - Mapping: CAPTION_TO_QWEN3_DIR dictionary
   - Example: human_checked_augmented_caption → qwen3_augmented
   - .pt file contains {result: [{caption, text_embedding}]}

6. PATH RESOLUTION
   - Relative paths in JSON
   - Joined with data_dir at runtime (typically "data/motionhub")
   - Becomes absolute path during prepare_data()

================================================================================
REQUIRED VS OPTIONAL FIELDS IN DATA_LIST ENTRIES
================================================================================

REQUIRED (always present):
✓ smplx_path (motion file)
✓ num_frames (integer)
✓ fps (float)
✓ duration (float)
✓ has_hand (boolean)
✓ subset (string)
✓ At least ONE caption field (hierarchical_caption_path preferred)

OPTIONAL:
- music_path, genre, sr (for music/dance tasks)
- audio_path, speech_script_path, speaker_id (for speech tasks)
- language (metadata)

================================================================================
TRANSFORM PIPELINE OUTPUT
================================================================================

After prepare_data():
{
    "motion_path": absolute/path,
    "caption_path": absolute/path,
    "num_frames": int,
    "fps": float,
    "duration": float,
    "has_hand": bool,
    "subset": str,
    ... (other optional fields)
}

After LoadCompatibleCaption:
{
    ... (all above) ...
    "caption": str,              // One randomly selected
    "caption_list": [str, ...],  // All available captions
    "granularity": str,          // (Legacy format only)
    "granularity_list": [str],   // (Legacy format only)
}

After LoadPreExtractedTextEmbedding (if .pt found):
{
    ... (all above) ...
    "text_vec_raw": Tensor[768],         // CLIP-L embedding
    "text_ctxt_raw": Tensor[seq, 4096],  // Qwen3 embedding
    "text_ctxt_raw_length": Tensor,      // Sequence length
    "_text_is_null": bool,               // False if loaded
}

If no .pt file:
{
    ... (all above) ...
    "text_vec_raw": Tensor[1, 768],      // All zeros
    "text_ctxt_raw": Tensor[1, 4096],    // All zeros
    "text_ctxt_raw_length": Tensor(0),   // Zero (signals null)
    "_text_is_null": bool,               // True
}

================================================================================
MULTI-PERSON SUPPORT
================================================================================

Single-person entry:
{
    "smplx_path": "path/to/motion.npz",
    ...
}

Multi-person entry:
{
    "smplx_path": [
        "path/to/person0/motion.npz",
        "path/to/person1/motion.npz"
    ],
    "num_person": 2,  // Optional explicit field
    ...
}

The dataset automatically detects:
- isinstance(smplx_path, str) → num_person = 1
- isinstance(smplx_path, list) → num_person = len(smplx_path)
