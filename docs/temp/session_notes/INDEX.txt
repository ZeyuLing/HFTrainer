================================================================================
                        KEY FACTS CHEAT SHEET
================================================================================

1. EULER ORDER: ZYX
   └─ Hardcoded in both directions
   └─ Can't change one without breaking the other
   └─ Always radians (degrees=False)

2. QPOS STRUCTURE:
   ├─ [0:3]   = Trans [x, y, z]
   ├─ [3:7]   = Root quat [x, y, z, w] ← NOT Euler
   ├─ [7:10]  = Joint 1 Euler (ZYX)
   ├─ [10:13] = Joint 2 Euler (ZYX)
   └─ Pattern continues...

3. ROOT SPECIAL:
   └─ NOT reordered (inserted before reordering)
   └─ Quaternion (4 DOF), not Euler angles
   └─ Global frame

4. BODY JOINTS:
   └─ Reordered via smpl_2_mujoco
   └─ Euler angles (3 DOF each)
   └─ Local frame

5. REORDER MAPPING:
   ├─ smpl_2_mujoco = [SMPL indices in MuJoCo order]
   ├─ Created: list comprehension over MuJoCo bodies
   ├─ Used: reshape → index → reshape pattern
   └─ NOT applied to root quaternion

6. BODY_POS[1] OFFSET:
   ├─ Forward: ADD (relative → absolute)
   ├─ Inverse: SUBTRACT (absolute → relative)
   ├─ Default: [0, 0, 0.91437225]
   └─ Symmetric (operations cancel out)

7. QUATERNION FORMAT:
   ├─ scipy: [w, x, y, z]
   ├─ MuJoCo: [x, y, z, w]
   ├─ Encode: [:, [3, 0, 1, 2]]
   └─ Decode: [:, [1, 2, 3, 0]]

8. CAVEATS:
   ├─ ⚠️  Euler order not flexible
   ├─ ⚠️  Quaternion format mismatch
   ├─ ⚠️  Root not reordered
   ├─ ⚠️  body_pos[1] handling asymmetric
   └─ ⚠️  Default standing height may not fit all models
