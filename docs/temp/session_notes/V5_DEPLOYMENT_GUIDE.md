## What Changed from V4 to V5

### New Components Generated

1. **SMPL Joints** (`data/smpl_joints/`)
   - Generated using `batch_npz_to_smpl_joints.py`
   - Extracts original 22-joint human skeleton from T2M output
   - Format: 30 FPS, Y-up coordinate system, compatible with Three.js
   - **Reason**: V5 inherited motion IDs with `motion_` prefix, needed regeneration

2. **Motion Text Mapping** (`motion_text_mapping.json`)
   - Generated by mapping V4 text prompts to V5 motion IDs
   - Converts `v4_xxx` → `motion_v4_xxx` ID scheme
   - **Reason**: V5 uses different naming convention

3. **Tracker Summary** (`data/tracked_caches/tracker_summary.json`)
   - Generated from V5 manifest physics information
   - Maps `fell` flag and `fall_frame` from manifest to tracker format
   - **Reason**: V5 uses integrated manifest format instead of separate tracker file

### ID Naming Difference

- **V4 IDs**: `v4_walk_001`, `v4_arm_002`, etc.
- **V5 IDs**: `motion_v4_walk_001`, `motion_v4_arm_002`, etc.
- **Reason**: V5 batch processor adds `motion_` prefix to distinguish retargeted outputs

### Data Quality Metrics

Both V4 and V5 are fully functional. V5 shows improvements in kinematic smoothness:


## Troubleshooting

### Issue: "SMPL joints not loading"
**Solution**: Check that `/data/smpl_joints/` contains 115 JSON files.

### Issue: "Motion text showing as None"
**Solution**: Verify `motion_text_mapping.json` exists and has 115 motion entries.

### Issue: "Tracker information not showing"
**Solution**: Check that `data/tracked_caches/tracker_summary.json` exists and is valid JSON.

### Issue: "Physics-tracked motion not rendering"
**Solution**: Verify `data/tracked_motions/` contains all 115 motion JSON files.
