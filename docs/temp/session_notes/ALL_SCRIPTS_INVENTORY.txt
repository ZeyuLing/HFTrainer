EXECUTION FLOW FOR DEMO DATA GENERATION
───────────────────────────────────────────────────────────────────────────────

1. physflow_precompute_text.py
   → Encode curriculum prompts with Qwen3-8B + CLIP-L
   → Save: output/physflow/text_embeddings.pt

2. physflow_trainer.py (optional if model_final.pt already exists)
   → Iteratively train on curriculum
   → Save: output/physflow/model_final.pt

3. physflow_eval_and_export.py ⭐ MAIN STEP
   Load models → Curriculum prompts → Generate motion_135
   → Apply physics correction (oracle)
   → Export motion_135 NPZ + SMPL mesh JSON
   → Compute metrics
   → Save: output/physflow/eval_demo/

4. (Optional) pipeline_motion_to_robot.py
   → Retarget to G1 robot motion
   → Save: robot .motion files in eval_demo/data/robot_motion/
