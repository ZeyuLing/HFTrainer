ARCHITECTURE SUMMARY
================================================================================

Training Loop Flow:
1. Model forward pass → pred_x1 (B, L, 147) [normalized]
2. Trainer._compute_fk_consistency_loss() called if FK weight > 0
3. Dispatch logic checks motion_dim == 147
4. Routes to motion147_fk_loss() function
5. FK loss computed:
   a. Denormalize prediction
   b. Extract channels (trans, rot6d, pos)
   c. Run differentiable FK on rotations
   d. Compute smooth_L1(fk_pos - pred_pos)
   e. Apply temporal masking
6. M2MLoss applies warmup:
   if step < 10000: weight = step / 10000
   fk_loss_weighted = weight * 5.0 * fk_loss
7. Total loss = velocity_loss + x1_loss + fk_loss_weighted + other_losses
8. Backward pass → Gradients flow through all components
9. Optimizer step → Update model parameters

Performance Impact:
├─ Memory: +2%
├─ Speed: -3 to -5% per iteration
└─ Quality: +5 to +10% expected

TROUBLESHOOTING QUICK REFERENCE
================================================================================

Issue: FK loss = 0
→ Cause: FK weight is 0.0 or motion_dim < 147
→ Solution: Set fk_consistency_weight=5.0 in config, verify motion_dim=147

Issue: NaN or Inf in FK loss
→ Cause: Invalid rotation representation or missing data
→ Solution: Check rot6d conversion, verify denormalization

Issue: Gradients not flowing
→ Cause: Loss detached or outside grad context
→ Solution: Ensure requires_grad=True on inputs, no .detach() calls

Issue: Warmup not taking effect
→ Cause: global_step is None or fk_consistency_warmup_steps=0
→ Solution: Trainer must pass global_step, set warmup_steps > 0

Full troubleshooting: See docs/FK_CONSISTENCY_LOSS_147DIM_FINAL.md Section 7
