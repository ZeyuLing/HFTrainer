================================================================================
ROBOT ANIMATION JSON - DATA FORMAT REFERENCE
================================================================================

This document describes the formats of motion data as it flows through the
PhysFlow embodied agent pipeline.

================================================================================
1. INPUT: motion_135 NPZ (SMPL Human Kinematics)
================================================================================

File Location: output/physflow/eval_demo/data/npz/*.npz

Array Name:    motion_135
Shape:         (T, 135) where T = number of frames
Data Type:     float32

Structure:
  Columns 0-2:    Root translation [X, Y, Z]
  Columns 3-134:  22 joints × 6 DOF rotation (rot6d)

Coordinate System (SMPL):
  - Z-axis: vertical (up)
  - Y-axis: forward
  - X-axis: right
  - Root position: ~1.14m height (human pelvis in SMPL)

Frame Rate: 30 fps (from npz metadata)

Typical Ranges:
  Root X: -0.05 to +0.05 m (horizontal)
  Root Y: 1.10 to 1.15 m (HEIGHT - NOT what robot expects!)
  Root Z: -0.03 to +2.38 m (typically very small, except walking shows 2.36m!)

Example Data (first 3 frames of "stands still"):
  Frame 0: [0.001934, 1.162407, -0.018396, rot6d_data...]
  Frame 1: [0.003090, 1.162217, -0.016518, rot6d_data...]
  Frame 2: [0.004004, 1.162817, -0.017460, rot6d_data...]

Key Points:
  - Y coordinate ~1.16m is CORRECT for human in SMPL frame
  - Z displacement +2.36m in walking is UPWARD motion (coordinate issue)
  - This data needs retargeting to G1 robot frame and scale

================================================================================
2. INTERMEDIATE: PyRoki Keypoints (.npy)
================================================================================

File Location: output/physflow/eval_demo/data/robot_mesh_rl/
                 motion_files/intermediates/keypoints/*.npy

Array Name:    (stored as numpy .npy file)
Shape:         (T, 18, 3) where T = number of frames
Data Type:     float32

Structure:
  18 keypoints extracted from SMPL skeleton:
    - Root (pelvis)
    - Head
    - Left/Right shoulders, elbows, wrists
    - Spine, chest
    - Left/Right hips, knees, ankles
    - Left/Right feet
    - (Auxiliary points for better retargeting)

Coordinate System (Z-up):
  - Z-axis: vertical (up)
  - Y-axis: forward
  - X-axis: right
  - Transformed from SMPL to be more suitable for G1

Example:
  frames shape: (90, 18, 3)
  Each frame has 18 keypoints, each with [X, Y, Z] position

Metadata (also stored):
  - positions: (T, 18, 3)
  - orientations: (T, 18, 3, 3)
  - left_foot_contacts: (T, 2)
  - right_foot_contacts: (T, 2)

Status in Current Run:
  ✓ Successfully generated for all motions
  ✗ But retargeting step failed before using these keypoints

3. INTERMEDIATE: Robot NPZ (After Retargeting)
================================================================================

File Location: output/physflow/eval_demo/data/robot_mesh_rl/
                 motion_files/intermediates/retargeted/*.npz

Expected Array Names:
  - dof_pos: (T, num_dofs) - joint angles for G1 robot
  - dof_vel: (T, num_dofs) - joint velocities
  - body_pos: (T, num_bodies, 3) - body positions
  - body_rot: (T, num_bodies, 3, 3) - body rotations
  - contact_labels: (T, 2) - left/right foot contact

Coordinate System (Y-up, G1 frame):
  - Y-axis: vertical (up)
  - X-axis: forward
  - Z-axis: right
  - Root height: ~0.78m (G1 standing height)

================================================================================
4. INTERMEDIATE: ProtoMotions .motion Format
================================================================================

File Location: output/physflow/eval_demo/data/robot_mesh_rl/
                 motion_files/*.motion

Format:    Custom binary format (ProtoMotions library)

Contains (typically):
  - Frame rate: 30 fps (from input)
  - Control framerate: 50 Hz
  - Number of frames: T
  - Per-frame data:
    - Root position (X, Y, Z) [Y ~0.78m after retargeting]
    - Root quaternion (w, x, y, z)
    - Joint angles (num_dofs,) in radians
    - Joint velocities (num_dofs,)
    - Contact labels (left, right)
