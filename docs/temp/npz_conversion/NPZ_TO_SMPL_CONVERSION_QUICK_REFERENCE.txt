📍 SCRIPT LOCATION
  scripts/embodied/batch_npz_to_smpl_mesh_json.py

🔄 PRIMARY FUNCTIONS
  1. convert_single_npz(npz_path, smpl_type="smplh", gender="neutral") -> dict
  2. rot6d_to_axis_angle_np(rot6d: np.ndarray) -> np.ndarray

📥 INPUT: motion_135 NPZ FORMAT
  Keys:
    - motion_135: np.ndarray shape (T, 135), dtype float32
    - fps: int (typically 30)
    - prompt: str (motion description)

  Structure per frame (135 values):
    [0:3]   → Translation [tx, ty, tz]
    [3:135] → 22 joints × 6D rot6d each (row-major rotations)

📊 OUTPUT: SMPL MESH JSON FORMAT
  Structure:
    {
      "type": "frames",
      "fps": 30,
      "frames": [
        [{
          "id": 0,
          "gender": "neutral",
          "smpl_type": "smplh",
          "Rh": [[rx, ry, rz]],              // Root orientation (axis-angle)
          "Th": [[tx, ty, tz]],              // Root translation
          "poses": [[p0, p1, ..., pN]],      // All joints axis-angles (flattened)
          "shapes": [[0, 0, ..., 0]],        // Always 16 zeros (no beta)
          "mocap_framerate": 30
        }],
        ...
      ]
    }

💾 POSES ARRAY SIZE BY SMPL TYPE
  SMPL:    72 dims  (root 3 + body 69)
  SMPL+H: 156 dims  (root 3 + body 63 + hands 90)
  SMPL-X: 165 dims  (root 3 + body 63 + jaw 3 + eyes 6 + hands 90)
  
  Note: motion_135 → 22 joints → 66 dims, rest zero-padded

🔁 ROTATION CONVERSION PIPELINE
  Row-major rot6d [R00, R01, R10, R11, R20, R21]
    ↓ Reorder indices [0,2,4,1,3,5]
    ↓ Extract columns a1=[first 3], a2=[last 3]
    ↓ Gram-Schmidt orthogonalization (b1, b2, b3=cross(b1,b2))
    ↓ Stack into 3×3 rotation matrix
    ↓ scipy.spatial.transform.Rotation.from_matrix().as_rotvec()
    → Axis-angle [rx, ry, rz]
