================================================================================

FILE STRUCTURE:
  Keys: ['motion_135', 'fps', 'prompt']
  
  motion_135: shape (T, 135) where T = frame count

    [3:135]    = 22 joints × 6 rot6d (132 values)
                 = rot6d for root + 21 body joints
  
  fps: integer, typically 30
  prompt: string description of motion

JOINT STRUCTURE (22 total):
  Joint 0:     Root (Pelvis)
  Joints 1-21: Body joints (21 body joints)
    - Spine (3), Neck, Head
    - Left/Right arms (shoulder, elbow, wrist)
    - Left/Right legs (hip, knee, ankle)
    - Left/Right toes

ROT6D ENCODING (per joint):
  6 floats = first two columns of 3×3 rotation matrix
  Row-major order: [R00, R01, R10, R11, R20, R21]
  Requires orthogonalization via Gram-Schmidt

7. TRANSFORMATION PROCESS
================================================================================

TRANSLATION:
  Source: motion_135[:, 0:3]
  Target: JSON "Th" (root translation)
  Process: Direct copy to output

ROTATION:
  Source: motion_135[:, 3:9] (root joint rot6d, joint 0)
  Process:
    1. Reorder from row-major [R00,R01,R10,R11,R20,R21] 
       to column-major [R00,R10,R20,R01,R11,R21]
    2. Gram-Schmidt orthogonalization to complete 3×3 matrix
    3. Compute cross product for third column
    4. Use scipy.spatial.transform.Rotation.from_matrix().as_rotvec()
    5. Convert 3×3 rotation → 3-element axis-angle vector
  Target: JSON "Rh" (root orientation, axis-angle)

BODY POSES:
  Source: motion_135[:, 9:135] (joints 1-21, 21×6 rot6d = 126 values)
  Process: Apply rot6d→axis-angle to each of 21 body joints
  Target: JSON "poses" 
    - For SMPL-H: 156 total params
    - [0:3] root axis-angle (duplicated from Rh)
    - [3:66] 21 body joints × 3 (63 params)
    - [66:156] hand joint placeholders (90 zeros)
