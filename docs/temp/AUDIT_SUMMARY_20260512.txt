KEY FINDINGS
================================================================================

1. B1 (Bundle-level Parameters) — FIXED ✅
   - Fixed by explicit __bundle_params__ tracking in bundle.py
   - v2 runner syncs orphan param grads via _sync_orphan_param_grads()
   - Fully synchronized across all DDP ranks
   → REMOVE from v2 bug sections

2. B2-ext (Null Embedding Source) — PARTIALLY FIXED ⚠️
   - Config fix is ready but UNCOMMITTED (working directory only)
   - Running Phase 2 task (launched 2026-05-08) launched WITHOUT the fix
   - Impact: 10% of training batches see all-zero null embeddings (CFG disabled)
   - Training quality degraded, not catastrophic
   - Inference would be broken (but not attempted yet)
   → COMMIT config changes and RESTART Phase 2 task

3. B3 (VACE Reactive Leak) — FIXED ✅
   - Fixed by explicit zero-masking: src_motion = src_motion * (1 - src_mask)
   - Trainer explicitly zeros mask=1 regions before VACE input
   - No information leak to reactive channel
   → REMOVE from v2 bug sections

4. B4 (Spurious CFG) — NOT AN ISSUE ✅
   - v1 had cond_mask_prob default=1.0 (broken)
   - v2 explicitly sets cond_mask_prob=0.0 in base, 0.1 in caption configs
   - Never uses problematic default value
   → REMOVE from v2 bug sections

5. B5 (Task Collapse) — NOT APPLICABLE ✅
   - v1 used implicit task indicators (could cause mode collapse)
   - v2 uses explicit mask sampling (unambiguous task definition)
   - Root cause fixed by architecture design
   → REMOVE from v2 bug sections

6. B6 (DDP State Dict Crash) — NOT AN ISSUE ✅
   - v1 used dist.broadcast on incompatible DDP state_dict
   - v2 uses Accelerator's load_state (DDP-safe abstraction)
   - No direct dist.broadcast, no crashes
   → REMOVE from v2 bug sections

7. B7 (DDP Orphan Sync) — v3-ONLY 🔵
   - Appears in v1 and v3, not in v2
   - v2 fixed via __bundle_params__ + _sync_orphan_param_grads()
   - v3 CRFM trainer encounters different edge case with state_dict
   → MOVE to v3-only section, REMOVE from v2

8. B8 (TAL Null-vs-Null) — v3-ONLY 🔵
   - Only v3 CRFM trainer has text_available flag tracking
   - v2 doesn't have this logic path
   - v3-specific edge case for null-vs-null comparison
   → MOVE to v3-only section, REMOVE from v2
