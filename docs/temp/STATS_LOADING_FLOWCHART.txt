KEY FINDINGS

1️⃣  THREE SOURCES (priority order):
    • mean_std_dir files (primary, in __init__)
    • Checkpoint buffers (secondary, in load_state_dict, OVERRIDES primary)
    • Defaults: zero/unit (tertiary, only if no files and no checkpoint)

2️⃣  T2M CURRENT SETUP:
    • Config references non-existent directory
    • Falls back to defaults in __init__
    • Checkpoint load OVERWRITES with correct 201-dim stats
    • Result: ✅ WORKS (but fragile)

3️⃣  M2M v2 ≠ T2M:
    • M2M v2: 198-dim (trans + rot6d + position)
    • T2M: 201-dim (trans + rot6d only)
    • Stats NOT interchangeable

4️⃣  SAFETENSORS LIMITATION:
    • .safetensors can't store bundle-level buffers
    • If saved as .safetensors, mean/std are LOST
    • Must rely on mean_std_dir files for .safetensors models

5️⃣  PRODUCTION RECOMMENDATION:
    • Always specify mean_std_dir in config
    • OR ensure checkpoint has stats buffers
    • Verify dimension matching (201 for T2M, 198 for M2M v2, etc)
