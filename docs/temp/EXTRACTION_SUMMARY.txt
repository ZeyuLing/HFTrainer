CRITICAL CONFIG CHANGES (Phase 2b vs Base)
───────────────────────────────────────────

Change 1: velocity_loss_reduction='component_mean'
  Before: 'element_mean' → translation ~1.5% of loss (drowned by body_rot)
  After:  'component_mean' → translation 25% of loss (equal with other 3 groups)
  Reason: Body rotation (126D) was dominating element-mean reduction

Change 2: trans_dim_weight=1.0 (down from 5.0)
  Before: 5.0 with element_mean → mild correction
  After:  1.0 with component_mean → exact balance (component_mean already 25%)
  Reason: 5.0 × 25% = 125% → overcorrection to ~55%

  After:  M2MLoss.fk_consistency_weight=0.0, KIMODO active
  Reason: KIMODO runs in world space (metres), better skating suppression

KEY INSIGHTS
────────────

1. Component_mean is critical for phase 2b success
   • Prevents body_rot from drowning out translation
   • But requires careful trans_dim_weight tuning

2. KIMODO has 3 complementary terms
   • joint_pos prevents pelvis "cheating"
   • joint_vel catches residual skating (pervasive at scale)
   • fk_consistency teaches intra-prediction equivalence

3. Foot skating root cause
   • Relative-pelvis encoding allows (pelvis, leg-static) illusion
   • Element-mean loss hides this (body_rot dominant)
   • KIMODO visible in world space (cannot be hidden)

4. Position channels have dual purpose
   • Supervised via M2MLoss (component_mean)
   • Enforced via KIMODO fk_consistency loss
   • Enables position-only edits at inference

5. Rotation space (local) is fixed for v2
   • All configs use rotation_space='local'
   • Global rotation supported but not used in phase 2b
