┌─ MOTION CACHE FORMAT ──────────────────────────────────────────────────────┐

Each .pt file contains:
  • dof_pos:      (T, 29)      → Joint angles in radians
  • dof_vel:      (T, 29)      → Joint velocities (rad/s)
  • body_pos:     (T, 33, 3)   → 33 rigid body positions (meters)
  • body_rot:     (T, 33, 4)   → 33 body rotations (xyzw quaternions)
  • body_vel:     (T, 33, 3)   → Body linear velocities
  • body_ang_vel: (T, 33, 3)   → Body angular velocities
  • control_dt:   float        → Timestep = 0.02s (50 Hz)
  • num_frames:   int          → Total frames

Example: hymotion_real_cache.pt
  487 frames × 29 DOFs = 14,123 joint angle data points
  487 frames × 33 bodies = 16,071 body positions
  COMPLETE kinematic state for comparison metrics
