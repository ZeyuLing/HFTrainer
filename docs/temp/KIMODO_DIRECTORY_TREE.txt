LEGEND
======
★★★  = HIGHEST PRIORITY / PRIMARY ENTRY POINT
★★   = VERY IMPORTANT / CORE FUNCTIONALITY
★    = IMPORTANT / INTEGRATION POINT
(no) = SUPPORTING / UTILITY

KEY FILE LOCATIONS FOR RETARGETING
===================================
Retargeting Implementation:
  → motion_annot_web/kimodo_constraint_demo/batch_eval.py (smpl_to_soma30_constraints)
  → ref_repo/KIMODO/kimodo/skeleton/definitions.py (SOMASkeleton30/77, FK)

Retargeting Tests:
  → motion_annot_web/kimodo_constraint_demo/test_retarget.py ★★★
  → Run: python test_retarget.py --num_cases 100 --verbose

Main Inference:
  → scripts/kimodo/run_kimodo_all_tasks.py ★★★
  → Usage: python run_kimodo_all_tasks.py --all-tasks --max-samples 80

Post-Processing:
  → scripts/kimodo/append_kimodo_context_soma77.py (add context SOMA-77 mesh)
  → scripts/patch/patch_kimodo_y_anchor.py (fix height drift)

Evaluation Dashboard:
  → motion_annot_web/eval_dashboard/app.py (web UI)
  → motion_annot_web/eval_dashboard/utils.py (SOMA skeleton defs)
  → motion_annot_web/eval_dashboard/swap_to_swin_kimodo.py (DB migration)

Database:
  → motion_annot_web/eval_dashboard/eval_dashboard.db (SQLite)
  → Tables: eval_runs, sample_results, agg_metrics, models, baselines

Training Integration:
  → hftrainer/models/motion/hymotion_m2m/network/kimodo_aux_loss.py
  → configs/hymotion_m2m_v3/_base_hymotion_m2m_v3_046b.py
