EXECUTIVE SUMMARY

The Eval Dashboard (motion_annot_web/eval_dashboard/) is a Flask web app for 
visualizing HyMotion M2M v2 evaluation results:

- Database: SQLite with 5 tables
- Visualization: 3D SMPL meshes (Three.js)
- Data Format: NPZ files (motion_135: 135D)
- Port: 8081 (default)
- Data Import: CLI tool (data_importer.py)

================================================================================
NPZ FILE FORMAT
================================================================================

Motion135 (135-dimensional motion vector):

Frame i = [
  tx, ty, tz,                           (3D translation, root position)
  r6d_0[6], r6d_1[6], ..., r6d_21[6]   (22 joints x 6D rotation)
]

Shape: (T, 135) where T = num frames
Total: 3 + 22*6 = 3 + 132 = 135

6D Rotation Representation:
- Elements 0-2: First column (normalized)
- Elements 3-5: Second column (normalized & orthogonalized)
- Third column: Computed as cross product

Conversion to axis-angle (3D):
1. Build 3x3 matrix from 6D
2. Extract axis-angle via Rodrigues formula

Reordering (important!):
row-major (NPZ): [R00, R01, R10, R11, R20, R21]
          ↓
column-major: [R00, R10, R20, R01, R11, R21]
Reorder: [0, 2, 4, 1, 3, 5]

================================================================================
DATABASE SCHEMA
================================================================================

models table:
  id (INTEGER PRIMARY KEY)
  name (TEXT) — model name
  checkpoint_path (TEXT)
  rotation_space (TEXT) — "local" or "global"
  has_caption (BOOLEAN)
  epoch (INTEGER)

eval_runs table (CORE):
  id (INTEGER PRIMARY KEY)
  model_id (FOREIGN KEY → models.id)
  task_id (TEXT) — "E14", "E15", etc
  setting (TEXT) — "M", "L", etc
  timestamp (TEXT)
  num_samples (INTEGER)
  result_json_path (TEXT)
  notes (TEXT)

sample_results table (DATA):
  id (INTEGER PRIMARY KEY)
  eval_run_id (INTEGER FOREIGN KEY)
  sample_idx (INTEGER) — 0-99
  prompt_id (TEXT) — sample ID
  text_caption (TEXT)
  motion_path (TEXT) — path to NPZ (MUST EXIST)
  gen_motion_path (TEXT)
  num_frames (INTEGER)
  metrics_json (TEXT) — JSON with all metrics

agg_metrics table:
  id (INTEGER PRIMARY KEY)
  run_id (INTEGER FOREIGN KEY)
  metric_name (TEXT)
  value (REAL)

CRITICAL: motion_path in sample_results must point to actual NPZ files!

================================================================================
API ENDPOINTS
================================================================================

/api/smpl/<path:npz_path>
  Purpose: Return per-frame SMPL parameters for mesh rendering
  Query params: rotation_space ("local" or "global")
  Response: {frames: [...], num_frames, fps}
  Caching: LRU (1024 entries), ETag-based browser cache
  Performance: 150-300ms (first), 1ms (cached)

/api/npz/<path:npz_path>
  Purpose: Return FK joint positions for skeleton
  Response: {positions: [...], edges: [...], joint_names: [...], fps}

/task/<task_id>
  Purpose: Task summary with metrics table + radar chart
  Example: http://localhost:8081/task/E14

/compare?runs=1,2,3
  Purpose: Multi-model comparison side-by-side
  Features: 3D viewers + radar charts + statistics

/viewer?path=<npz>
  Purpose: Standalone NPZ viewer without database

  - Applies per-frame poses

            "mpjre": s.get("mpjre"),
            "trans_error_mm": s.get("trans_error_mm"),

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: "404 Not Found" on 3D Viewer

Symptom: Clicking "View 3D" shows 404 error
Cause: _npz_path in database doesn't match actual file
Fix: Check if file exists, ensure absolute paths, verify permissions

ISSUE: Motion Looks Twisted/Broken

Symptom: Skeleton or mesh is distorted
Cause: Rotation space mismatch
Fix: Try rotation_space=global in URL or reimport with correct setting

ISSUE: Metrics Show NaN

Symptom: Aggregated metrics are empty
Cause: NPZ corrupted or metrics not computed
Fix: Verify evaluation completed, check disk space, rerun with --save-npz

ISSUE: Server Crash on API Call

Symptom: 500 error or crash
Cause: SMPL module not installed
Fix: pip install -e /path/to/hftrainer

PERFORMANCE
================================================================================

Server-Side LRU Cache:
- maxsize: 1024 entries
- Key: (npz_path, rotation_space, file_mtime)
- Typical size: 300-500 MB (worst-case 3 GB)

Browser Cache:
- /api/smpl/... : ETag-based (mtime-aware)
- /api/npz/... : 1-day cache

Performance Numbers:
First load (miss):  150-300 ms
Repeat load (hit):  ~1 ms
JSON compression:   50-100 ms
Three.js render:    60 FPS (real-time)
