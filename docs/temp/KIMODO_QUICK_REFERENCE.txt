┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 1. KIMODO MOTION FEATURE LAYOUT (333 dims total, 27-joint skeleton)                                    │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                         │
│  ┌─ DIMS [0:3] ─────────────────────────────────────────────────────────────────────────────────────┐  │
│  │ smooth_root_pos = [x_smooth, y_absolute, z_smooth]                                             │  │
│  │ - XZ: heavily smoothed via ADMM (margin ±0.06 m)                                               │  │
│  │ - Y: raw pelvis height (NOT smoothed)                                                          │  │
│  │ - Relationship: smooth_root_pos ≈ filtered_pelvis_position                                     │  │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                                         │
│  ┌─ DIMS [3:5] ──────────────────────────────────────────────────────────────────────────────────────┐  │
│  │ global_root_heading = [cos(ψ), sin(ψ)]                                                        │  │
│  │ - ψ = heading angle around Y-axis (in radians)                                                 │  │
│  │ - Computed from hip vector: atan2(z_component, -x_component)                                  │  │
│  │ - Inverse: psi = atan2(heading[1], heading[0])                                                │  │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                                         │
│  ┌─ DIMS [5:86] ─────────────────────────────────────────────────────────────────────────────────────┐  │
│  │ local_joints_positions = 27 joints × [x_rel, y_abs, z_rel]                                    │  │
│  │ - XZ: relative to smooth_root_pos (enables easy translation)                                  │  │
│  │ - Y: absolute height (preserves individual joint heights)                                      │  │
│  │ - Formula: pos_local = pos_global - [smooth_root_x, 0, smooth_root_z]                        │  │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                                         │
│  ┌─ DIMS [86:248] ───────────────────────────────────────────────────────────────────────────────────┐  │
│  │ global_rot_data = 27 joints × 6D continuous rotation (WORLD FRAME, NOT local!)               │  │
│  │ - 6D = first two rows of 3×3 rotation matrix in column-major order                           │  │
│  │ - NOT parent-dependent (critical difference from SMPL local rotations)                        │  │
│  │ - Enables direct imputation of world-space constraints (no IK needed)                         │  │
│  │ - Conversion: matrix ↔ 6D via cont6d_to_matrix() / matrix_to_cont6d()                       │  │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                                         │
│  ┌─ DIMS [248:329] ──────────────────────────────────────────────────────────────────────────────────┐  │
│  │ velocities = 27 joints × [vx, vy, vz]                                                        │  │
│  │ - Formula: vel = fps × (pos[t] - pos[t-1])                                                   │  │
│  │ - NOT constrained during diffusion (derived from positions)                                   │  │
│  │ - Used in loss computation for smoothness                                                     │  │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                                         │
│  ┌─ DIMS [329:333] ──────────────────────────────────────────────────────────────────────────────────┐  │
│  │ foot_contacts = [L_heel, L_toe, R_heel, R_toe] ∈ {0, 1}                                     │  │
│  │ - Thresholds: pos_height < 0.15m AND vel_magnitude < 0.10 m/s                                │  │
│  │ - NOT constrained (computed from positions + velocities)                                      │  │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 2. HYMOTION M2M CURRENT ROOT REPRESENTATION (138 dims total, SMPL-22)                                 │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                         │
│  ┌─ DIMS [0:3] ──────────────────────────────────────────────────────────────────────────────────────┐  │
│  │ abs_translation = [abs_x, abs_y, abs_z]                                                      │  │
│  │ - Absolute world position of pelvis                                                           │  │
│  │ - First frame: [0, 0, 0] (arbitrary reference)                                               │  │
│  │ - Cumulative: abs[t] = abs[t-1] + rel[t]                                                     │  │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                                         │
│  ┌─ DIMS [3:6] ──────────────────────────────────────────────────────────────────────────────────────┐  │
│  │ rel_translation = [rel_x, rel_y, rel_z]                                                      │  │
│  │ - Relative velocity: rel[t] = abs[t] - abs[t-1]                                              │  │
│  │ - More stable for differencing than raw positions                                             │  │
│  │ - Heading implicitly in (rel_x, rel_z) direction                                              │  │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                                         │
│  ┌─ DIMS [6:138] ────────────────────────────────────────────────────────────────────────────────────┐  │
│  │ local_joint_rots_6d = 22 joints × 6D (PARENT-RELATIVE, SMPL convention)                     │  │
│  │ - LOCAL coordinate frame (depends on parent joint rotation)                                   │  │
│  │ - Requires FK to compute global positions for world-space constraints                        │  │
│  │ - Hierarchical: child rotation depends on parent                                              │  │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 3. CONVERSION PIPELINE: SMPL PELVIS ↔ KIMODO ROOT                                                     │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                         │
│  FORWARD (SMPL → KIMODO):                                                                            │
│  ─────────────────────────                                                                            │
│    1. FK: local_rot[T,J,3,3] → global_rot[T,J,3,3], global_pos[T,J,3]                               │
│    2. Heading: from hip vector → [cos ψ, sin ψ]                                                      │
│    3. Smooth: root_pos → smooth_root_pos (ADMM filter, margin ±0.06m)                               │
│    4. Local positions: global_pos - [smooth_root_x, 0, smooth_root_z]                               │
│    5. 6D rotations: global_rot_matrices → 6D continuous                                              │
│    6. Velocities & contacts: from positions                                                          │
│                                                                                                         │
│  INVERSE (KIMODO → SMPL):                                                                            │
│  ────────────────────────                                                                             │
│    1. 6D → matrices: global_rot_data → global_rot_matrices[T,J,3,3]                                  │
│    2. Global → Local: global_rot_matrices → local_rot_matrices (IFK via parent^T @ child)           │
│    3. Recover positions: local_pos + [smooth_root_x, 0, smooth_root_z]                              │
│    4. Extract pelvis: root_pos = smooth_root_pos (approximately)                                     │
│    5. Optional FK: local_rot + root_pos → final posed_joints                                         │
│                                                                                                         │
│  ⚠️  LOSSY CONVERSION: Smoothing removes high-frequency details                                       │
│      Recovery ≈ original (smoothing already applied to root position)                                 │
│                                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 4. CONSTRAINT TYPES & IMPUTATION MECHANISM                                                            │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                         │
│  Constraint Type           │ Affected Dims  │ Purpose                                                │
│  ───────────────────────────┼────────────────┼─────────────────────────────────────────────────────  │
│  smooth_root_2d            │ [0, 2]         │ Constrain 2D trajectory (X,Z plane only)             │
│  root_y_pos                │ [1]            │ Constrain pelvis height                              │
│  global_root_heading       │ [3:5]          │ Constrain heading [cos ψ, sin ψ]                     │
│  global_joints_rots        │ [86:248]       │ Constrain per-joint global rotations (6D per joint)  │
│  global_joints_positions   │ [5:86]         │ Constrain per-joint world positions (3D per joint)   │
│                                                                                                       │
│  IMPUTATION MECHANISM (before each denoising step):                                                  │
│  ─────────────────────────────────────────────────                                                    │
│    1. Create: observed_motion[T, 333], motion_mask[T, 333]                                           │
│    2. Fill: observed_motion[frame, dims] = constraint_value                                          │
│    3. Mark: motion_mask[frame, dims] = True                                                          │
│    4. Enforce: x_t = x_t * (1 - mask) + observed * mask  ← Direct imputation                        │
│    5. Input: concat([x_t, mask]) → Transformer as extra channels                                     │
│    6. Output: Transformer predicts denoising for unconstrained dims                                   │
│                                                                                                       │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 5. ROTATION REPRESENTATION: CRITICAL CONVERSIONS                                                      │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                         │
│  6D ROTATION (Row-Major vs Column-Major):                                                             │
│  ────────────────────────────────────────                                                             │
│    Training data (HyMotion): rot6d_row = [R[0,0], R[0,1], R[1,0], R[1,1], R[2,0], R[2,1]]          │
│    Library (rotation_convert): rot6d_col = [R[0,0], R[1,0], R[2,0], R[0,1], R[1,1], R[2,1]]        │
│                                                                                                         │
│    Reorder: _ROW_TO_COL = [0, 2, 4, 1, 3, 5]  (row → col)                                           │
│    Reorder: _COL_TO_ROW = [0, 3, 1, 4, 2, 5]  (col → row)                                           │
│                                                                                                         │
│  LOCAL ↔ GLOBAL ROTATION:                                                                             │
│  ────────────────────────                                                                             │
│    FK (Local → Global):                                                                               │
│      global[0] = local[0]                                                                            │
│      global[j] = global[parent[j]] @ local[j]                                                        │
│                                                                                                         │
│    IFK (Global → Local):                                                                              │
│      local[0] = global[0]                                                                            │
│      local[j] = global[parent[j]]^T @ global[j]  ← Note: inv(R) = R^T for rotation matrices        │
│                                                                                                         │
│  SMPL-22 KINEMATIC TREE:                                                                              │
│  ──────────────────────                                                                               │
│    Root (Pelvis): parent = -1                                                                        │
│    Legs: L/R Hip → L/R Knee → L/R Ankle → L/R Foot                                                   │
│    Spine: Pelvis → Spine1 → Spine2 → Spine3 → Neck → Head                                            │
│    Arms: Spine3 → L/R Collar → L/R Shoulder → L/R Elbow → L/R Wrist                                 │
│                                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 6. SMOOTH ROOT ALGORITHM (ADMM with Margin Constraints)                                               │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                         │
│  Objective: minimize ||x - x_original||^2 + λ||∇²x||^2                                              │
│             subject to: ||x[t] - target[t]|| ≤ margin[t]                                             │
│                                                                                                         │
│  Default Parameters:                                                                                  │
│    - margin: 0.06 m per frame (±6 cm allowable deviation)                                            │
│    - pos_weight: 0.0 (pure smoothing, no bias to original)                                           │
│    - admm_iters: 500 per multigrid level                                                             │
│    - alpha_overrelax: 1.8 (over-relaxation for convergence)                                          │
│                                                                                                         │
│  Multigrid Strategy:                                                                                  │
│    1. Start coarse (every 2^k frames) and solve                                                       │
│    2. Interpolate to finer resolution                                                                 │
│    3. Repeat until full resolution                                                                    │
│    4. Result: smooth trajectory respecting margin constraints                                         │
│                                                                                                         │
│  Application: XZ plane only (horizontal), Y stays raw (height preserved)                              │
│                                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────┘
