## Setup

Run commands from the repository root. Install the environment below, download the checkpoint, and prepare data before training.

```bash
python -m pip install -e .
python -m pip install "huggingface_hub>=0.34,<2"
```

Download the complete HFTrainer bundle below. Model weights are hosted separately from the code.

## Checkpoint

[ZeyuLing/HFTrainer-Stable-Diffusion-1.5](https://huggingface.co/ZeyuLing/HFTrainer-Stable-Diffusion-1.5) · [pinned revision](https://huggingface.co/ZeyuLing/HFTrainer-Stable-Diffusion-1.5/tree/0d794d6ba0ddabac7c15283a3c0c47fc86a07116)

This release packages real pretrained weights in a complete **HFTrainer bundle**. Trainer and Pipeline share the repository-owned `from_pretrained` loader. Conversion, source attribution and validation scope are recorded below.

```bash
hf download ZeyuLing/HFTrainer-Stable-Diffusion-1.5 \
  --revision 0d794d6ba0ddabac7c15283a3c0c47fc86a07116 \
  --local-dir checkpoints/hftrainer/sd15
export HFTRAINER_CHECKPOINT="$PWD/checkpoints/hftrainer/sd15"
```

[Conversion and validation record](evidence/checkpoints/sd15.json). Base weights are separate from demo adapters and datasets. To export a fine-tuned bundle:

```bash
python tools/export_model.py --config configs/pretrained/train_sd15.py \
  --checkpoint PATH_TO_TRAINING_CHECKPOINT --output outputs/sd15_export
```

## Data

Eight image/text pairs in `data/text2image/demo/metadata.jsonl`, with image paths relative to that directory.

## Train

```bash
python tools/train.py configs/pretrained/train_sd15.py
```

## Infer

Run the published pretrained model:

```bash
python tools/infer.py --config configs/pretrained/infer_sd15.py --device cuda \
  --prompt "A paper boat at dusk." --output outputs/sd15.png
```

For fine-tuned weights, pass `--checkpoint` with the training output and a matching training model config (including LoRA settings or a changed classification head).

## Evidence and loss

Checkpoint schema, tiny numerical parity and train/infer artifact round-trip checks.

The new pretrained training entry point completed one optimizer step and saved a checkpoint on an H200. These synthetic execution checks are recorded with the checkpoint evidence; they do not establish useful fine-tuning.

**Loss curve: not published.** No sustained-decrease or convergence result is claimed.

## Limitations

The short recipe and five-step validation sampler are not image-quality benchmarks.
