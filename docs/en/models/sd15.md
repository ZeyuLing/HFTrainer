## Setup

Run commands from the repository root. Prepare the listed weights and data first; a command is not a self-contained download or a claim of convergence.

```bash
python -m pip install -e .
```

Place the compatible checkpoint and tokenizer/config assets at `checkpoints/stable-diffusion-v1-5`. Weights are not bundled.

## Data

Eight image/text pairs in `data/text2image/demo/metadata.jsonl`, with image paths relative to that directory.

## Train

```bash
python tools/train.py configs/sd15/sd15_demo.py
```

## Infer

After training, use the saved checkpoint (adjust the step to a checkpoint that exists):

```bash
python tools/infer.py --config configs/sd15/sd15_demo.py \
  --checkpoint work_dirs/sd15_smoke/checkpoint-iter_10 \
  --prompt "A paper boat at dusk." --output outputs/sd15.png
```

## Evidence and loss

Checkpoint schema, tiny numerical parity and train/infer artifact round-trip checks.

**Loss curve: not published.** No sustained-decrease or convergence result is claimed.

## Limitations

The short recipe and five-step validation sampler are not image-quality benchmarks.
