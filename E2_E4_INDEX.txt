⚠️ CRITICAL NOTES:

1. CFG REQUIRES BOTH CONDITIONS:
   • uncondition_mode = False (allows conditioning)
   • cond_mask_prob > 0 (trains CFG capability)
   If either is wrong, CFG will not work!

2. TEXT EMBEDDINGS:
   • Primary: Pre-extracted .pt files (CLIP-L + Qwen3)
   • Fallback: null_embedding_source checkpoint
   If embedding .pt files missing, model uses fallback

3. ROOT REPRESENTATION:
   • E2: Plain SMPL root (raw translation [0:3])
   • E4: KIMODO root (ADMM smoothed on XZ plane, 6cm margin)
   This is the ONLY structural difference between E2 and E4

4. TIMESTEP WEIGHTING:
   • Base config: aux_timestep_squared_weighting=True
   • Effect: Suppresses noisy FK at high noise levels
   • Both E2 and E4 inherit this
