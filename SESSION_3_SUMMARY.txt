CRITICAL BUGS FIXED (From Previous Sessions)
================================================================================

BUG #1: Training/Inference Mismatch (CFG Mask Handling)
────────────────────────────────────────────────────────
File: hftrainer/trainers/motion/hymotion_m2m_trainer.py
Lines: 186-197 (pre-extracted text), 226-237 (online encoding)

Problem: When CFG randomly drops text embeddings during training, the attention
         mask wasn't updated. This created a mismatch:
         - Training: null embeddings could attend to L positions
         - Inference: null embeddings attend to 1 position
         Result: ~10% performance loss on caption training

Fix: Update ctxt_mask_temporal to [False, ..., False, True] for dropped samples
Status: ✅ COMMITTED in git

BUG #2: M2M Inference CFG Disabled
───────────────────────────────────
File: tools/infer.py
Lines: 57-58 (CLI arg), 235 (pipeline call), 289 (another pipeline call)

Problem: M2M inference pipeline didn't receive text_guidance_scale parameter
         This disabled text guidance in M2M inference
         T2M had this, but M2M was missing it

Fix: Add --guidance-scale argument and pass to both M2M pipeline instances
Status: ✅ COMMITTED in git
