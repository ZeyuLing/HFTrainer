│ MOTION REPRESENTATION: OccamMotionRep (201-dim)
├─ Layout: [rot6d(132) | joint(66) | trans(3)]
│  └─ rot6d: column-major [R00,R10,R20,R01,R11,R21] (22 joints × 6)
│  └─ joint: global 3D positions (22 joints × 3)
│  └─ trans: root translation (3)
├─ Methods: encode(rotmat, joint, trans) → flatten
│          decode(motion) → (rotmat, joint, trans)
│          normalization(motion, ref_idx) → egocentric
│          kinematic_loss(rot6d, joint) → rigidity
└─ Key: global_pose=True uses global orientations

│ MODEL: MoreDiff (DiT with RoPE + Sliding Window)
├─ Input: motion(201) + mask(201) → 402 total
├─ Architecture:
│  ├─ Embed: linear(402 → d_model)
│  ├─ n_stack DiT blocks, each with:
│  │  ├─ RoPE on Q/K (no learnable params)
│  │  ├─ Sliding window attn (window=90, ±45 neighbors)
│  │  ├─ AdaLN (6 parameters per layer from cond+timestep)
│  │  └─ FFN (2x hidden, SiLU activation)
│  └─ Decode: linear(d_model → 201)
├─ Configs:
│  ├─ 0.03B: d_model=512, n_head=8, n_stack=8
│  ├─ 0.1B:  d_model=768, n_head=12, n_stack=12  ← Recommended
│  └─ 0.3B: d_model=1024, n_head=16, n_stack=18
└─ Output: predicted x_0 (clean motion)

│ DIFFUSION: GaussianDiffusion (1000 timesteps)
├─ Schedule: COSINE (smooth noise increase)
├─ Key parameters:
│  ├─ β_t ∈ [0.0001, 0.02] (COSINE schedule)
│  ├─ ᾱ_t = ∏(1-β_i), α̃_t = cumulative product
│  └─ Model predicts x_0 directly (ModelMeanType.START_X)
├─ Forward: x_t = √ᾱ_t * x_0 + √(1-ᾱ_t) * ε
│           (selective noising: obs_mask ≥ 0.99999 stays clean)
├─ Backward: sample from posterior N(μ, Σ_t)
└─ Methods: q_sample() → denoise with observed regions fixed
           p_sample() → reverse diffusion step

│ TRAINING: MoGenDitDistributedTrainer
├─ Setup: DDP multi-GPU, AdamW optimizer, EMA model
├─ Data pipeline:
│  ├─ Mask scheduling (which regions are "observed")
│  ├─ Motion degradation (50% of batches: add noise + jitter)
│  ├─ Forward diffusion: x_0 → x_t + noise_mask
│  └─ Wrap: [x_t | mask], padding_mask, condition
├─ Loss (3 components):
│  ├─ L_denoise = smooth_l1(pred_x0, x_0)
│  ├─ L_rigid = MSE(joint_offsets, init_offsets)  ← Skeleton rigidity
│  └─ L_drift = MSE(global_delta, velocity)       ← Motion consistency
├─ Training loop:
│  ├─ Producer thread: data prefetch to queue (size=12)
│  ├─ Forward: pred_x0 = model(x_wrapped, t)
│  ├─ Loss: total = L_denoise + w_rigid*L_rigid + w_drift*L_drift
│  ├─ Backward: clip gradients (1.0), optimizer.step()
│  └─ EMA: decay=0.999, start_step=2000
└─ Hyperparams: LR=1e-4, batch=64-256, max_iters=?

│ REFINEMENT: MoreDiffRefiner (3 modes)
├─ Denoise:      steps=10-50,    eta=1.0   (light, fast)
├─ Ada_denoise:  steps=10-50,    eta=varies (adaptive)
└─ Trans_regen:  steps=50-999,   eta=0.0   (thorough, slow)
│
├─ Fast sampling:
│  └─ custom_timesteps = [999,750,500,250,100,50,25,10,5,0]
│     Only 10 steps → 90% speedup, minor quality loss
│
├─ Windowed processing (for long sequences):
│  ├─ Window: 224 frames (~7.5s @ 30fps)
│  ├─ Overlap: 20 frames
│  ├─ Auto-cutoff: if character walks >4m, truncate window
│  └─ Pre-stitch each window to original motion
│
└─ Interface: refine(motion, cond, step, eta, mode, window_size, use_windowed)

│ PHYSICS: FlatGroundSimulator (optional)
├─ Purpose: enforce ground contact, friction constraints
├─ Dual PD control:
│  ├─ Angular: des_qddot = Kp(q_ref - q) - Kd*qdot
│  └─ Linear:  des_pddot = Kp(p_ref - p) - Kd*pdot
├─ QP optimization:
│  └─ Minimize: ||Jacobian @ qdot - des_pdot||²
│     (maps joint velocities to end-effector velocities)
├─ Contact handling:
│  ├─ Grounded: static friction |a_xz| ≤ μ(|a_y+g|)
│  ├─ Airborne: reduced horizontal control
│  └─ Jump detection: vertical momentum > gravity
└─ Params: G=9.8 m/s², μ=0.8, Kp=fps², Kd=fps
