================================================================================
MOTION REPRESENTATION
================================================================================

LATENT SPACE STRUCTURE (After VAE Encoding)
────────────────────────────────────────────

Shape after VAE encode: [B, 16, T', 23]
  - B: Batch size
  - 16: Latent channels (VAE output dimension)
  - T': Temporal dimension (frames in latent space)
  - 23: Motion tokens
    - Token 0: ROOT TRANSLATION (3D global position)
    - Tokens 1-22: JOINT ROTATIONS (22 SMPL joints, 6D rotation encoding)

For loss computation:
  - mse[:, :, :, :1]  → Translation MSE (shape [B, 16, T', 1])
  - mse[:, :, :, 1:]  → Rotation MSE (shape [B, 16, T', 22])


================================================================================
MASKING FLOW
================================================================================

1. PADDING MASK CREATION (Lines 50-56)
   Input:   num_frames = [32, 45, 40, ...]  (actual frames per batch element)
   Output:  padding_mask shape [B, 1, T', 1]
   Values:  1 = valid frame, 0 = padded frame

2. CONDITION MASK (Lines 67-71)
   Output:  condition_frame_mask_vae shape [B, 1, T', 1]
   Values:  1 = frame NOT conditioned (will have loss), 
            0 = frame IS conditioned (frozen, no loss)

3. EXPAND FOR MSE (Line 107-108)
   padding_mask.unsqueeze(1).expand_as(mse)
   → Shape [B, 16, T', 23]
   → Same mask replicated across all 16 channels and 23 tokens

4. FULL MASK COMBINATION (Line 108)
   full_mask = condition_mask * padding_mask
   → Loss = 0 for frames where:
     - Frame is padded (padding_mask=0) OR
     - Frame is conditioned (condition_mask=0)

5. APPLY TO LOSS (Lines 115, 119)
   loss = (mse * mask).sum() / mask.sum()
   → Normalized sum: only valid, unconditioned frames contribute


================================================================================
WEIGHT PARAMETER MEANINGS
================================================================================

translation_loss_weight = w_t ∈ [0, 1]
   w_r = 1 - w_t

   loss = w_t * loss_transl + w_r * loss_rot

Examples:
   w_t = 0.5  →  loss = 0.5 * loss_transl + 0.5 * loss_rot       (EQUAL)
   w_t = 0.3  →  loss = 0.3 * loss_transl + 0.7 * loss_rot       (Favor rotation)
   w_t = 0.04 →  loss = 0.04 * loss_transl + 0.96 * loss_rot     (Proportional to 1:22)
   w_t = 1.0  →  loss = loss_transl                              (Translation only)
   w_t = 0.0  →  loss = loss_rot                                 (Rotation only)
