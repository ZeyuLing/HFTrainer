║           PROTOMOTIONS MUJOCO INFERENCE CONTROL FLOW (50Hz CONTROL LOOP)       ║
╚════════════════════════════════════════════════════════════════════════════════╝

┌─────────────────────────────────────────────────────────────────────────────────┐
│ INITIALIZATION (simulator.py._create_simulation, lines 294-383)                  │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                   │
│  1. Load MJCF file                                                               │
│     └─ _load_mjcf_stripped(): Remove sensors, add ground/lights                 │
│                                                                                   │
│  2. Zero passive forces (jnt_stiffness, dof_damping) = 0                         │
│     ↳ We'll handle PD control via actuators                                      │
│                                                                                   │
│  3. Override joint properties (_override_joint_properties)                        │
│     ├─ dof_armature: from robot_config.control.control_info                     │
│     ├─ dof_frictionloss: zeroed                                                 │
│     └─ actuator_gear: UNCHANGED (left at MJCF default)  ← KEY POINT            │
│                                                                                   │
│  4. Build actuator-to-DOF mapping (_build_actuator_mapping)                      │
│     ├─ Map: DOF[i] → Actuator[j]                                                │
│     └─ Used for routing control commands                                         │
│                                                                                   │
│  5. Cache PD gains (_setup_control_parameters)                                   │
│     ├─ _kp[num_dofs]: stiffness values                                           │
│     ├─ _kd[num_dofs]: damping values                                             │
│     └─ _effort_limits[num_dofs]: torque limits                                   │
│                                                                                   │
│  6. Configure actuators based on PD mode                                         │
│     ├─ IF use_implicit_pd=True:                                                 │
│     │  └─ _configure_actuators_for_pd()                                         │
│     │     ├─ Set actuator_gainprm[i,0] = kp[i]                                  │
│     │     ├─ Set actuator_biastype[i] = mjBIAS_AFFINE (1)                        │
│     │     ├─ Set actuator_biasprm[i] = [0, -kp[i], -kd[i]]                      │
│     │     └─ Result: MuJoCo position actuators (implicit PD)                     │
│     │                                                                             │
│     └─ ELSE use_implicit_pd=False:                                              │
│        └─ _configure_explicit_pd()                                              │
│           ├─ Keep motor actuators (no PD built-in)                               │
│           └─ We'll compute torques manually per substep                          │
│                                                                                   │
│  7. Extract COM offsets (_extract_body_com_offsets)                              │
│     └─ For IsaacGym velocity semantics matching                                  │
│                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────┐
│ CONTROL LOOP: ONE 50ms CONTROL STEP (Decimation = 20)                            │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                   │
│  ┌─ STEP 1: Get observation from simulator                                       │
│  │          └─ Get robot state, velocity, contact forces, etc.                   │
│  │                                                                                │
│  ├─ STEP 2: Policy inference (PyTorch/ONNX model forward pass)                   │
│  │          └─ Input: current observation                                        │
│  │          └─ Output: actions [num_envs, num_dofs]                              │
│  │             (Either position targets or torques)                               │
│  │                                                                                │
│  ├─ STEP 3: Apply acceleration clamp (optional)                                  │
│  │          └─ Limit jerk: max second derivative of position targets             │
│  │                                                                                │
│  └─ STEP 4: Call simulator.step(actions)                                         │
│             │                                                                     │
│             ├─ BASE SIMULATOR (simulator.py._physics_step, lines 748-790):       │
│             │                                                                     │
│             │  a. Call _apply_control() ← HAPPENS ONCE PER 50ms STEP             │
│             │     │                                                               │
│             │     ├─ For BUILT_IN_PD mode:                                       │
│             │     │  │  targets = actions (position targets)                     │
│             │     │  │  Convert to sim DOF order                                 │
│             │     │  │  Call _apply_simulator_pd_targets(targets)                │
│             │     │  └─ MuJoCo: data.ctrl[actuator] = target_position            │
│             │     │                                                               │
│             │     ├─ For PROPORTIONAL mode:                                      │
│             │     │  │  Get current dof_pos and dof_vel                          │
│             │     │  │  Compute: torques = kp * (targets - q) - kd * qd          │
│             │     │  │  Clip torques to effort limits                            │
│             │     │  └  Call _apply_simulator_torques(torques)                   │
│             │     │                                                               │
│             │     └─ For TORQUE mode:                                            │
│             │        │  torques = actions (direct torques)                        │
│             │        │  Clip to effort limits                                     │
│             │        └─ Call _apply_simulator_torques(torques)                   │
│             │                                                                     │
│             ├─ MUJOCO PHYSICS LOOP (lines 764-779):                              │
│             │                                                                     │
│             │  FOR i = 0 to 19 (20 physics substeps):  ← DECIMATION = 20        │
│             │                                                                     │
│             │    IF use_implicit_pd=True:                                        │
│             │    │  └─ mujoco.mj_step(model, data)                               │
│             │    │     ├─ MuJoCo reads data.ctrl[j] = position target[j]         │
│             │    │     ├─ For each actuator at 1kHz:                             │
│             │    │     │  force = gainprm[0] * ctrl - kp * q - kd * qd           │
│             │    │     │        = kp * (ctrl - q) - kd * qd  ← PD TORQUE        │
│             │    │     ├─ Apply force to joint                                    │
│             │    │     └─ Update q, qd via physics integration                    │
│             │    │                                                                │
│             │    ELSE (use_implicit_pd=False AND BUILT_IN_PD):                   │
│             │    │  ├─ _recompute_explicit_pd()  ← RECOMPUTE AT EACH SUBSTEP   │
│             │    │  │  ├─ Read current q, qd from simulation                     │
│             │    │  │  ├─ Compute: torque[j] = kp * (target[j] - q[j]) - kd*qd[j]
│             │    │  │  ├─ Clip to effort limits                                  │
│             │    │  │  └─ Write to data.ctrl[actuator] = torque                  │
│             │    │  │                                                             │
│             │    │  └─ mujoco.mj_step(model, data)                               │
│             │    │     ├─ MuJoCo reads data.ctrl[j] = torque[j]                  │
│             │    │     ├─ Apply torque to joint                                  │
│             │    │     └─ Update q, qd via physics integration                   │
│             │    │                                                                │
│             │    ELSE (TORQUE or PROPORTIONAL mode):                             │
│             │    │  └─ mujoco.mj_step(model, data)                               │
│             │    │     ├─ MuJoCo reads data.ctrl[j] = torque[j]                  │
│             │    │     ├─ Apply torque to joint                                  │
│             │    │     └─ Update q, qd via physics integration                   │
│             │    │                                                                │
│             │  ├─ data.cvel computed (body velocities)                            │
│             │  └─ data.xpos, data.xquat updated (body poses)                     │
│             │                                                                     │
│             │  END FOR                                                            │
│             │                                                                     │
│             ├─ Sync viewer if active                                             │
│             │                                                                     │
│             └─ Return to step 1 (repeat at 50Hz)                                 │
│                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────┐
│ KEY TIMING SUMMARY                                                                │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                   │
│  Control loop:              50 Hz (20ms between steps)                            │
│  Physics simulation:        1000 Hz (1ms timestep)                                │
│  Decimation:                20 physics steps per control step                     │
│                                                                                   │
│  Policy inference:          Once per 20ms                                        │
│  _apply_control():          Once per 20ms                                        │
│  Physics stepping:          20 × mujoco.mj_step() per 20ms                       │
│                                                                                   │
│  If implicit PD:            PD computed at 1kHz (20× per control step)            │
│  If explicit PD:            PD computed at 1kHz (20× per control step)            │
│  If PROPORTIONAL:           PD computed once per control step, held constant     │
│  If TORQUE:                 Torque held constant over 20 physics steps            │
