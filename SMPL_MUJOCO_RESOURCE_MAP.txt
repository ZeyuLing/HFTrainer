┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. QUICK START USAGE                                                        │
└─────────────────────────────────────────────────────────────────────────────┘

Step 1: Load model & create simulator
   import mujoco
   model = mujoco.MjModel.from_xml_file('smpl_humanoid.xml')
   data = mujoco.MjData(model)

Step 2: Convert SMPL pose to MuJoCo
   from phc.smpllib.smpl_mujoco import smpl_to_qpose
   smpl_pose = np.random.randn(1, 72)  # 72D pose (angle-axis)
   smpl_trans = np.array([[0, 0, 1.0]])  # 3D translation
   qpos = smpl_to_qpose(smpl_pose, model, trans=smpl_trans)

Step 3: Apply to simulator & step physics
   data.qpos[:] = qpos
   for _ in range(100):
       mujoco.mj_step(model, data)

Step 4: Extract simulated pose back to SMPL
   from phc.smpllib.smpl_mujoco import qpos_to_smpl
   pose_sim, trans_sim = qpos_to_smpl(data.qpos, model)

│ 6. CONTACT & FOOT STABILITY FEATURES                                        │
└─────────────────────────────────────────────────────────────────────────────┘

Existing Infrastructure:
   ✓ Contact force tracking          → data.contact, data.cfrc_ext
   ✓ Feet bodies tagged              → L_Ankle, L_Toe, R_Ankle, R_Toe
   ✓ Friction model                  → Coulomb (1.0 tangent coeff)
   ✓ Contact impedance               → Tuned via solimp/solref

Known Limitations:
   ⚠ Footskate can occur under fast motions
   ⚠ No explicit contact velocity constraints
   ⚠ Box feet geometry (not deformable)

Potential Improvements (references available):
   1. Increase friction coefficients in XML
   2. Lower contact solver tolerance (solref)
   3. Add contact Jacobian-based IK
   4. Reference: UnderPressure/ or LODGE/dld/losses/foot_contact.py
