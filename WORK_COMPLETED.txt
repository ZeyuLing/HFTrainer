4. KEY TECHNICAL FINDINGS
═════════════════════════════════════════════════════════════════════════════════

MIMIC OBSERVATION PIPELINE:
→ Entry: MimicControl.populate_context()
→ Core operation: Batched MotionLib queries for efficiency
→ Output: Root-relative, heading-aligned observations
→ Transformations: World frame → root-relative → heading-aligned
→ Result shapes: [num_envs, future_steps, num_bodies, 3/4]

MUJOCO STATE EXTRACTION (_get_simulator_bodies_state):
→ Positions: self.data.xpos (world frame)
→ Rotations: self.data.xquat (wxyz format)
→ Velocities: self.data.cvel + COM offset correction
→ Angular velocities: self.data.cvel (world frame)

FRAME TRANSFORMATIONS:
→ Root-relative: body_pos - root_pos
→ Heading-aligned: quat_rotate(heading_inv_rot, relative_pos)
→ heading_inv_rot: Removes yaw only, preserves pitch/roll
