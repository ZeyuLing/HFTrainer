DATA FORMATS
================================================================================

MOTION_135 FORMAT
──────────────────────────────────────────────────────────────────────────────
Shape: (T, 135) where T = number of frames

Layout:
  [0:3]        → Translation (root X, Y, Z position)
  [3:9]        → Root rotation (6D rotation representation)
  [9:135]      → Body pose (21 joints × 6D each)

Total dimensions: 3 + 6 + (21 × 6) = 135

NPZ FILE STRUCTURE
──────────────────────────────────────────────────────────────────────────────
{
  'motion_135': np.ndarray (T, 135),      # Motion data
  'fps': 30,                               # Frame rate
  'prompt': str,                           # Text prompt
  'rl_status': 'success' | 'fell'         # Physics outcome (optional)
}

KEY METRICS
──────────────────────────────────────────────────────────────────────────────
Metric              Meaning                         Range  Good Value
─────────────────────────────────────────────────────────────────────
completion_ratio    Fraction of motion completed    0-1    > 0.8
root_height_min     Lowest point in simulation      meters > 0.3 m
status              Did motion succeed?             success success
actual_sim_steps    Frames before falling           int    ≈ 200
total_sim_steps     Expected total frames           int    200

FREQUENTLY ASKED QUESTIONS
================================================================================

Q: What's in each NPZ file?
A: motion_135 array (120 × 135) + fps (30) + prompt string

Q: Why 4 files per prompt?
A: Pretrained (raw) + Pretrained (RL) + Fine-tuned (raw) + Fine-tuned (RL)

Q: What does RL-corrected mean?
A: Motion was run through MuJoCo physics simulator for stability/compliance

Q: How is "success" determined?
A: completion_ratio > 0.99 (99% of motion completed without falling)

Q: What's completion_ratio?
A: Fraction of original motion that completed before the character fell (0-1)

Q: Where's the visualization code?
A: physflow_visualize_compare.py (main) + physflow_rl_oracle.py (physics)

Q: Can I view the motions?
A: Yes, use motion_annot_web or embodied_viz with the NPZ files

Q: How long does a full comparison take?
A: ~15-20 minutes on GPU (Phases 1-2: ~10 min, Phases 3-4: ~5-10 min)

Q: Can I modify parameters?
A: Yes, edit PHYSFLOW_VISUALIZATION_CODE_REFERENCE.md → "Main Function"
