## Technical Details

### SMPL Joints Format
```json
{
  "fps": 30,
  "num_frames": 120,
  "joint_names": ["Pelvis", "L_Hip", "R_Hip", ...],
  "joint_parents": [-1, 0, 0, ...],
  "bones": [[0,1], [0,2], ...],
  "frames": [
    {"joints": [[x,y,z], [x,y,z], ..., [x,y,z]]},
    ...
  ]
}
```

**Key Properties**:
- 30 FPS (vs 50 FPS for robot motions)
- 22 SMPL joints (original T2M skeleton)
- Y-up coordinates (Three.js compatible)
- Frame mapping: robot_frame → smpl_frame via time

### Coordinate System Conversions
- **MuJoCo**: Z-up (0, 0, 1)
- **Three.js**: Y-up (0, 1, 0)
- **Conversion**: 90° X-axis rotation applied in browser

### Motion ID Scheme
- **V4**: `v4_walk_001`, `v4_arm_002`, `v4_gesture_003`
- **V5**: `motion_v4_walk_001`, `motion_v4_arm_002`, `motion_v4_gesture_003`
- **Reason**: V5 batch processor adds `motion_` prefix to distinguish generated outputs
