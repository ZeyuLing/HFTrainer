📋 KEY TECHNICAL SPECIFICATIONS

Input Format: motion_135 NPZ
  Structure: [transl(3) + 22*rot6d(132)] per frame
  Dimensions: T × 135 (T=40-120)
  FPS: 30 (from metadata)

Output Format: SMPL-H Mesh JSON
  Schema: { "type": "frames", "fps": 30, "frames": [...] }
  Per-frame: { id, gender, smpl_type, Rh, Th, poses, shapes, mocap_framerate }
  Poses: 156 parameters (root 3 + body 63 + hands 90)
  Compression: 6.3× vs input (81 MB → 12.9 MB)

Conversion Pipeline
  1. Load: Extract motion_135 array and fps metadata
  2. Split: Separate translation (T×3) and rot6d (T×22×6)
  3. Convert: rot6d → axis-angle via Gram-Schmidt
  4. Map: SMPL-H structure (22 joints → 52 SMPL-H joints)
  5. Serialize: Compact JSON format to disk
