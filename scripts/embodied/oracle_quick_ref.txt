STEP 2: yup_to_zup() [Lines 245–286]

  *** CRITICAL: Transforms ALL 24 joints (including body local frames) ***
  Output: smpl_pose_zup(T,72) Z-up, transl_zup(T,3) Z-up

STEP 3: smpl_to_qpos() [Lines 321–426]
  SMPL 72-dim AA → MuJoCo 76-dim qpos
  [root_trans(3) | root_quat_wxyz(4) | body_euler_xyz(69)]
  *** Includes joint limit handling: guard axes centered, main axes clamped ***
  Output: ref_qpos(T,76)

STEP 3.5: compute_ground_offset() [Lines 471–522]
  Find min foot z across ALL frames → ground_offset (float)
  Apply: ref_qpos[:, 2] -= ground_offset
  Output: ground-adjusted ref_qpos(T,76)

STEP 4: run_physics_sim() [Lines 609–717]
  *** MAIN PHYSICS LOOP ***
  For each frame t:
    1. Set root position/quat = reference (kinematic tracking)
    2. Compute root velocity from finite differences (smooth interpolation)
    3. Set body joint PD targets: ctrl[:] = ref_qpos[t, 7:69]
    4. Step MuJoCo physics (decimation × sub-steps)
    5. Record simulated qpos
    6. Detect fall (root_h < 0.15m or NaN)
  Output: sim_qpos(T',76) [T' ≤ T], stats dict with tracking error

STEP 4.5: smooth_simulated_qpos() [Lines 720–795]
  Remove PD oscillation via Savitzky-Golay (333ms window)
  Blend: α × filtered_sim + (1-α) × ref (default α=0.5)
  Root NOT smoothed (stays kinematic)
  Output: smoothed sim_qpos(T,76)

STEP 5: qpos_to_smpl() [Lines 429–464]
  MuJoCo 76-dim qpos → SMPL 72-dim AA
  Inverse of smpl_to_qpos()
  Output: smpl_pose_sim(T,72) Z-up, transl_sim(T,3) Z-up

STEP 5.3: smooth_smpl_poses() [Lines 802–890]
  Remove Euler↔AA conversion jitter via quaternion-space smoothing
  Adaptive windowing: large rotations get wider window
  Two-pass smoothing for convergence
  Output: smoothed smpl_pose_sim(T,72) Z-up

STEP 5.5: Undo ground offset
  transl_sim[:, 2] += ground_offset
  (preserve original absolute height)

STEP 6: zup_to_yup() [Lines 289–314]
  MuJoCo Z-up → SMPL Y-up (inverse of step 2)
  Output: smpl_pose_yup(T,72) Y-up, transl_yup(T,3) Y-up

STEP 7: smpl_to_mesh_json() [Lines 893–933]
  Convert to web visualizer JSON format
  Output: {type: "frames", fps: N, frames: [...]}

FINAL OUTPUT: JSON + stats
  • {stem}.json: mesh visualization JSON
  • {stem}.json (in stats_dir): simulation statistics

def run_physics_sim(model, data, ref_qpos: (T,76), fps=30):
    """PD-tracking physics sim with kinematic root
    
    For t in 0..T:
      data.qpos[:7] = ref_qpos[t, :7]           # Root kinematic
      data.qvel[:3] = (ref_qpos[t+1,:3] - ref_qpos[t,:3]) / dt
      data.qvel[3:6] = R_diff.as_rotvec() / dt  # Root angular velocity
      data.ctrl[:] = ref_qpos[t, 7:]             # Body PD targets
      for _ in range(decimation): mujoco.mj_step()
      record sim_qpos
      check fall (root_h < 0.15m)
    """
    → sim_qpos: (T', 76), stats: dict

================================================================================
PHYSICS QUALITY METRICS
================================================================================

FALL DETECTION: root_h < 0.15m or NaN

GROUND CONTACT: compute_ground_offset()
  • Scan 30 evenly-spaced frames (or all if T ≤ 30)
  • Find min foot z = min(xpos[L_Toe,z], xpos[R_Toe,z], xpos[L_Ankle,z], xpos[R_Ankle,z])
  • ground_offset = min foot z across all frames
  • Apply: ref_qpos[:, 2] -= ground_offset (ensures feet at z=0)

TRACKING ERROR: mean(|sim_qpos[:, 7:] - ref_qpos[:, 7:]|)  [radians]
  • Computed on body joints only (indices 7:76)
  • Root position drift = |sim_qpos[-1, :3] - ref_qpos[-1, :3]|

JERK METRICS: 3rd finite difference (n=3)
  • raw_jerk = mean(|Δ³(sim_body)| * fps³)
  • smooth_jerk = mean(|Δ³(smoothed_body)| * fps³)
  • jerk_reduction = (1 - smooth_jerk/raw_jerk) * 100%

STATS OUTPUT:
  {
    "completed": bool,               # No fall
    "total_frames": int,
    "simulated_frames": int,
    "fall_frame": int or None,
    "joint_tracking_error_rad": float,
    "root_position_drift_m": float,
    "min_root_height_m": float,
    "ground_offset_m": float,
    "fps": int,
    "decimation": int
  }

                    800     18      Shoulder abduct/adduct

L_Hand / R_Hand     200      9      Hand (low gain)

Tracking time constant: τ = kd/kp ≈ 0.02s = 0.6 frames @ 30fps
Critical damping: ζ = kd/(2√(kp*arm)) = 1.0 (with armature=0.1)
