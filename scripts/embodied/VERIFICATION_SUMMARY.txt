3. GRAM-SCHMIDT ORTHOGONALIZATION
   Status: ✓ VERIFIED
   
   Process:
   1. Extract first column a1, second column a2
   2. Normalize a1 → orthonormal b1
   3. Orthogonalize a2 against b1 → b2
   4. Normalize b2
   5. Cross product b1 × b2 → b3
   6. Stack [b1, b2, b3] → 3×3 rotation matrix
   
   Local: motion135_to_smplx.py:44-52
   
   Verification: Implementation matches official specification exactly
