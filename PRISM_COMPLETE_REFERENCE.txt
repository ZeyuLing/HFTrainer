SMPLX-55 FORMAT (Stored Format)
================================================================================

Each NPZ file contains motion in SMPLX-55 skeletal format with axis-angle rotations:

Data Layout:
  transl              (T, 3)     float32    Root translation [x, y, z]
  global_orient       (T, 3)     float32    Root rotation [axis-angle] = 3 params
  body_pose           (T, 63)    float32    21 joints × 3 [axis-angle] = 63 params
  jaw_pose            (T, 3)     float32    Jaw joint [axis-angle]
  leye_pose           (T, 3)     float32    Left eye [axis-angle]
  reye_pose           (T, 3)     float32    Right eye [axis-angle]
  left_hand_pose      (T, 45)    float32    15 left hand joints [axis-angle]
  right_hand_pose     (T, 45)    float32    15 right hand joints [axis-angle]
  
  poses               (T, 165)   float32    Concatenation of pose components
                                            (excludes transl): global_orient + body_pose
                                            + jaw + eyes + hands
  
  betas               (10,)      float32    SMPL shape parameters (usually all zeros)
  expression          (T, 10)    float32    Facial expression coefficients
  gender              ()         string     "neutral", "male", or "female"
  mocap_framerate     ()         float64    Frame rate, usually 30.0 Hz

Format dimensionality:
  - Stored poses: 3 + 3 + 63 + 3 + 3 + 45 + 45 = 165 (without translation)
  - Full SMPLX-55: 3 + 165 = 168 dimensions

Sample values:
  T (frames): 37 to 301 (mean ~193, median ~203)
  Duration:   1.2s to 10s (mean ~6.4s @ 30fps)


135-DIMENSIONAL FORMAT (Evaluation Format)
================================================================================

The 135D format is used by eval_with_motionclip_evaluator.py for metrics:

Conversion process:
  1. Extract subset of 22 joints from SMPLX-55 (root + 21 body joints)
  2. Convert axis-angle rotations to rotation matrices (3×3)
  3. Extract 6D representation (first 2 rows flattened)
  4. Concatenate: translation(3D) + 22 joints × 6D(132D) = 135D

Final layout:
  [0:3]      Translation [x, y, z]
  [3:9]      Joint 0 - 6D rotation (root/hips)
  [9:15]     Joint 1 - 6D rotation (right hip)
  [15:21]    Joint 2 - 6D rotation (right knee)
  ...
  [129:135]  Joint 21 - 6D rotation (last joint)

22-joint skeleton (HumanML3D standard):
  0   Hips/Pelvis (root)
  1   Right Hip
  2   Right Knee
  3   Right Ankle
  4   Left Hip
  5   Left Knee
  6   Left Ankle
  7   Spine
  8   Chest/Thorax
  9   Neck
  10  Head
  11  Right Shoulder
  12  Right Elbow
  13  Right Wrist
  14  Left Shoulder
  15  Left Elbow
  16  Left Wrist
  17-21 Additional joints (hands, feet, etc.)

6D rotation representation:
  - More numerically stable than quaternions for neural networks
  - Derived from first 2 rows of 3×3 rotation matrix
  - Can be normalized to exact rotation: R = Q @ Q^T where Q is (3×2) stacked 6D

Convert SMPLX-55 to 135D:

  from scipy.spatial.transform import Rotation
  
  def axis_angle_to_rotation_matrix(axis_angle):
      """Convert (N, 3) axis-angle to (N, 3, 3) rotation matrices"""
      r = Rotation.from_rotvec(axis_angle)
      return r.as_matrix()
  
  def rotation_matrix_to_6d(rot_mat):
      """Convert (N, 3, 3) rotation matrix to (N, 6) 6D representation"""
      return rot_mat[:, :2, :].reshape(rot_mat.shape[0], 6)
  
  def convert_to_135d(data):
      """Convert SMPLX-55 to 135D format"""
      transl = data['transl']                    # (T, 3)
      global_orient = data['global_orient']      # (T, 3)
      body_pose = data['body_pose']              # (T, 63)
      
      T = transl.shape[0]
      
      # Extract 22 joints (root + first 21 body joints)
      all_rotations = np.concatenate([global_orient, body_pose], axis=1)  # (T, 66)
      selected_joints = all_rotations[:, :66]  # Select 22 joints × 3
      
      # Convert axis-angle to rotation matrices
      rot_matrices = np.array([
          axis_angle_to_rotation_matrix(selected_joints[t:t+1])
          for t in range(T)
      ]).squeeze()  # (T, 22, 3, 3)
      
      # Convert to 6D
      rot_6d = np.array([
          rotation_matrix_to_6d(rot_matrices[t])
          for t in range(T)
      ])  # (T, 22, 6)
      
      rot_6d_flat = rot_6d.reshape(T, 132)
      
      # Combine translation + rotations
      motion_135d = np.concatenate([transl, rot_6d_flat], axis=1)
      
      return motion_135d.astype(np.float32)
  
  data = np.load("path/to/humanml3d_10006.npz")
  motion_135d = convert_to_135d(data)
  print(motion_135d.shape)  # (T, 135)
