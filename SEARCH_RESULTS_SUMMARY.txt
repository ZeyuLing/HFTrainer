RESEARCH METHODS FOUND
================================================================================

1. PRISM (Chapter 3): Text-to-Motion Generation
   - Architecture: Diffusion Transformer + 2D Causal VAE + Flow Matching
   - Key Achievement: FID 0.027 on HumanML3D (10x better than previous SOTA)

2. HyMotion M2M (Chapter 4): Fine-Grained Motion Editing
   - Architecture: Conditional Diffusion + VACE (4-channel conditioning)
   - Coverage: 25+ editing scenarios, E1-E16 tasks

3. MCM (Chapter 5): Audio-Driven Motion Synthesis
   - Architecture: ControlNet + Sparse control on PRISM base
   - Tasks: Music→Dance, Speech→Gesture with only +27% parameters

4. VerMo (Chapter 6): Multi-Modal Unified Framework
   - Architecture: LLM-based (Llama/Qwen) + VQ-VAE discretization
   - Tasks: 8+ motion understanding tasks in single model

EVALUATION METRICS IDENTIFIED
================================================================================

STANDARD T2M METRICS (Motion Generation):
1. FID (Fréchet Inception Distance)
   - Better: Lower (0-∞)
   - Interpretation: < 0.05 = Excellent, 0.05-0.1 = Very good, > 0.3 = Poor
   - PRISM achieves: 0.027 (HML3D), 0.055 (MotionHub)

2. R-Precision@K (Recall@K for Text-Motion Alignment)
   - Better: Higher (0-1)
   - Variants: @1 (strictest), @3 (most lenient)
   - PRISM achieves: 0.893@3 on HML3D (vs 0.906 real motion)
   - Gap to human: Only 1.4%

3. MM-Dist (Multi-Modal Distance)
   - Better: Lower (0-2)
   - Measures: CLIP embedding distance between text and motion
   - PRISM achieves: 0.937 on HML3D
   - Interpretation: < 1.0 = Excellent alignment

4. Diversity (Motion Variation)
   - Better: Higher (up to real motion value)
   - Target: ≈ 21.7 on HumanML3D (matches real motion)
   - PRISM achieves: 21.70 (nearly perfect)
   - Issue: Too low = Mode collapse, too high = Unrealistic

M2M EDITING METRICS (Motion-to-Motion):
5. MPJPE (Mean Per-Joint Position Error)
   - Better: Lower
   - Units: Meters (typically reported in mm)
   - Variants: masked (generated dims), unmasked (known dims)
   - Evaluation: FK-based position computation

6. Jitter (3rd-order finite difference)
   - Better: Lower
   - Measures: Acceleration discontinuities
   - Purpose: Smoothness indicator

7. Foot Skating Ratio
   - Better: Lower (< 0.05 is good)
   - Measures: Unnatural foot contact/penetration
   - Purpose: Physical plausibility

8. Boundary Accel Jump
   - Better: Lower
   - Measures: Acceleration at mask transitions
   - Purpose: In-betweening quality

9. End-Effector Error
   - Variants: mean, p50, p95, max
   - Hit rates: @5cm, @10cm
   - Purpose: Constraint satisfaction

AUDIO-DRIVEN METRICS:
10. BeatAlign
    - Better: Higher
    - Measures: Audio-motion synchronization
    - Specific to: MCM dance/gesture tasks

11. Parameter Efficiency
    - MCM: +27% vs base model PRISM
    - Purpose: Lightweight expansion capability

KEY INSIGHTS
================================================================================

1. METRICS HIERARCHY
   - PRISM: FID/R-Precision/MM-Dist/Diversity (T2M quality)
   - HyMotion M2M: MPJPE/Jitter/Skating/Boundary (Editing quality)
   - MCM: FID/BeatAlign/Efficiency (Audio alignment)
   - VerMo: R-Precision/Task Coverage (Multi-modal capability)

2. PERFORMANCE BREAKTHROUGH
   - PRISM FID: 0.027 is ~2x better than any prior work
   - Never seen: 10x improvement over older methods (MDM/MLD)
   - Generalization: Strong on both HML3D (clean) and MotionHub (diverse)

3. ARCHITECTURAL INSIGHTS
   - 2D VAE design (T×J structure) is critical for quality
   - Frame conditioning with 1 frame ≈ 9 frames of baseline
   - Causal convolution essential for autoregressive generation

4. PRACTICAL VALUE
   - M2M: 25+ scenarios from 6 base mask strategies (elegant design)
   - MCM: +27% parameters for 2 new tasks (parameter efficiency)
   - VerMo: 8+ tasks unified (knowledge sharing across modalities)

5. REMAINING CHALLENGES
   - Rotation loss: 2x higher than flow loss (optimization bottleneck)
   - Long sequence: Autoregressive generation shows drift/accumulation
   - Real-time inference: 50-step ODE solve not yet < 33ms/frame
