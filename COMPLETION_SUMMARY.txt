BUG DESCRIPTION
================================================================================

Symptom: After PyRoki retargeting, the G1 robot's feet face LEFT (sideways) 
         instead of FORWARD, despite the original SMPL motion having correct 
         forward-facing feet.

Root Cause: Local frame semantic mismatch between SMPL (Y-up) and Z-up 
            coordinate conventions:
            - SMPL defines "forward" for feet as +X in local frame
            - Z-up defines "forward" for feet as +Y in local frame
            - The coordinate transform only fixed world frame axes, not local 
              frame semantics

Error Magnitude: ~90° rotation around Z-axis

================================================================================
THE FIX
================================================================================

File: scripts/embodied/motion135_to_pyroki_keypoints.py
Function: transform_y_up_to_z_up()
Lines: 203-215 (13 new lines)

What was added:
- 90° rotation matrix around Z-axis (Rz_90deg)
- Applied to 4 foot joints (SMPL indices 7, 8, 10, 11)
- Reorients foot local frames from SMPL to Z-up semantics

Code:
    Rz_90deg = np.array([
        [0, -1, 0],
        [1, 0, 0],
        [0, 0, 1]
    ], dtype=np.float64)
    
    foot_smpl_indices = [7, 8, 10, 11]
    for idx in foot_smpl_indices:
        rotations_zup[:, idx] = rotations_zup[:, idx] @ Rz_90deg
