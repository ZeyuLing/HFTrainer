================================================================================
BUG #1: TRAINING/INFERENCE DISTRIBUTION MISMATCH
================================================================================

Problem:
  When CFG dropout masks text embeddings with nulls, the attention mask
  (ctxt_mask_temporal) wasn't updated. This caused a distribution mismatch:
  - Training: null embeddings saw variable attention (based on caption length)
  - Inference: null embeddings only saw position 0 (1 position)
  
  Expected result: ~10% performance degradation

Solution Applied:
  When text is dropped, update ctxt_mask_temporal to:
  - Set all positions to False
  - Set only position 0 to True
  - This matches the inference CFG null branch behavior

Code:
  if not text_available.all():
      dropped_samples = ~text_available
      ctxt_mask_temporal = ctxt_mask_temporal.clone()
      ctxt_mask_temporal[dropped_samples] = False
      ctxt_mask_temporal[dropped_samples, 0] = True

Expected Improvement: +~10% on caption training metrics

================================================================================
BUG #2: M2M INFERENCE CFG DISABLED
================================================================================

Problem:
  M2M inference tool was missing text_guidance_scale parameter:
  - T2M correctly passes this to enable CFG
  - M2M was not passing it, causing CFG to be disabled (scale = 1.0)
  - Result: Text guidance had no effect in M2M inference

Solution Applied:
  1. Added --guidance-scale CLI argument (default: 5.0)
  2. Passed text_guidance_scale parameter to M2M pipeline

Code:
  # Line 57-58
  parser.add_argument('--guidance-scale', type=float, default=5.0,
                      help='CFG scale for text-conditioned models (default: 5.0)')
  
  # Line 235
  text_guidance_scale=getattr(args, 'guidance_scale', 5.0) or 5.0,

Expected Improvement: Text guidance now works with configurable scale
