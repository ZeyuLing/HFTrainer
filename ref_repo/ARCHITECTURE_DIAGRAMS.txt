│                                                                           │

│              │                                                           │
│         ┌────┴──────────────────────────────────────────────────┐      │
│         ↓                                                        ↓      │
│    x_t (T,201)                                          E_ctx(s̃)     │
│       noisy                                              (0.207M)      │
│         │                                                        │      │
│         └──────────────────┬──────────────────────────────────┘      │
│                            ↓                                           │
│                     x'_emb = E_in(x_t) + E_ctx(s̃)                   │
│                     [Element-wise ADD at embedding level]             │
│                            │                                           │

─────────────────────────────────────────────────────────────────────────────
2. MASK GRANULARITY VISUALIZATION
─────────────────────────────────────────────────────────────────────────────

Example Task: Regenerate LEFT ARM ONLY (keep body, keep right arm)

UMO (Frame-Level Meta-Op) — CANNOT DISTINGUISH
────────────────────────────────────────────────
τ[t] = [E] for all t    ← "Edit" this frame
        ↓
ALL 22 JOINTS edited simultaneously
(No way to say "left arm only")

Result: Cannot do partial per-joint editing ❌


MotionLab (Modality Level) — Can use trajectory hint
─────────────────────────────────────────────────
source[t, joints 0-22]       ← Full source (including left arm)
hint[t, left_arm_joints]     ← Explicit trajectory constraint

In attention, left_arm dims in trajectory hint get stronger weight
But NOT native per-joint masking—via semantic constraint ⚠️


M2M (Dimension Level) — NATIVE PER-JOINT MASKING ✅
───────────────────────────────────────────────────
Left arm in 138D vector occupies dims 30-42 (example)

Binary mask:
mask[t, 0:30]   = 0    ← Keep body/root unchanged
mask[t, 30:42]  = 1    ← LEFT ARM: regenerate
mask[t, 42:138] = 0    ← Keep right arm + legs unchanged

VACE encoding:
inactive[t, 30:42] = 0  ← "I have no known values here"
reactive[t, 30:42] = 0  ← "I'm not ignoring known values"

Result: Model ONLY regenerates dims 30-42, keeps rest ✅ NATIVE

5. ATTENTION MECHANISM COMPARISON
─────────────────────────────────────────────────────────────────────────────

UMO: Backbone Self-Attention (No Explicit Cross-Modal)
──────────────────────────────────────────────────────
        Input Embedding (modified)
        x'_emb = E_in(x_t) + E_ctx(s̃)
             ↓
        Backbone Blocks
        ├─ Self-Attention (attends to all positions in modified embedding)
        │  (Implicitly learns to separate noisy target from context)
        └─ FFN
             ↓
        Output

Problem: No explicit interaction signal for source vs target
Solution: Model must infer from modified embedding implicitly


MotionLab: Explicit Joint Attention (Cross-Modal)
─────────────────────────────────────────────────
        Separate embeddings for 5 modalities
        ├─ source_emb:  (L, D)
        ├─ target_emb:  (L, D)
        ├─ text_emb:    (L, D)
        ├─ hint_emb:    (L, D)
        └─ style_emb:   (L, D)
             ↓
        JointAttention:
        Q = [Q_src | Q_tgt | Q_txt | Q_hint | Q_style]  (5L, D)
        K = [K_src | K_tgt | K_txt | K_hint | K_style]  (5L, D)
        V = [V_src | V_tgt | V_txt | V_hint | V_style]  (5L, D)
        
        Attention matrix shape: (5L, 5L)
        - src→tgt: Learn to copy/modify source to target
        - txt→tgt: Learn to incorporate text guidance
        - hint→tgt: Learn to follow trajectory
        - style→tgt: Learn to apply style
             ↓
        Split back to 5 outputs
             ↓
        Backbone

Advantage: Explicit cross-modal interaction signals


M2M: Single Input Encoder (Implicit Modality Handling)
──────────────────────────────────────────────────────
        Concatenated input
        [x_t | inactive | reactive | mask]  (T, 552)
             ↓
        input_encoder (552 → hidden_dim)
        ├─ Learns to separate channels implicitly
        └─ All dims processed together
             ↓
        Backbone Self-Attention
        (Attends over all 552-dim features)
             ↓
        Output

Trade-off: Simpler, but channels not explicitly separated like MotionLab

6. MOTION REPRESENTATION: What Information Each Carries
─────────────────────────────────────────────────────────────────────────────

Per-frame vector (1 timestep, T=1):

UMO (201D):
┌────────────────────────────────────────────────────────────────┐
│ Root Translation (3D)         [3]    ──→ Root XYZ position    │
│ Root Orientation (6D)         [6]    ──→ 6D rotation vector   │
│ 21 Joint Rotations (126D)     [126]  ──→ 21×6D rot vectors    │
│ 22 Joint Positions (66D)      [66]   ──→ 22×3D local xyz      │
│ ────────────────────────────────────                           │
│ TOTAL: 201D                                                     │
│                                                                  │
│ Enables: Direct trajectory control (via joint positions)       │
│ Example: Can say "constraint elbow to (x,y,z)"                 │
└────────────────────────────────────────────────────────────────┘

MotionLab (263D):
┌────────────────────────────────────────────────────────────────┐
│ Root Translation (3D)         [3]    ──→ Root XYZ             │
│ Root Velocity (3D)            [3]    ──→ Root velocity        │
│ Root Orientation (6D)         [6]    ──→ 6D rotation          │
│ 22 Joint Positions (66D)      [66]   ──→ 22×3D local xyz      │
│ 22 Joint Velocities (66D)     [66]   ──→ 22×3D velocity       │
│ 22 Joint Rotations (132D)     [132]  ──→ 22×6D rot vectors    │
│ Foot Contact (4D)             [4]    ──→ Binary foot contacts │
│ ────────────────────────────────────                           │
│ TOTAL: 263D                                                     │
│                                                                  │
│ Enables: All of UMO + velocity info + foot contact awareness  │
│ Example: Model learns walking patterns from contact signal    │
└────────────────────────────────────────────────────────────────┘

M2M (138D):
┌────────────────────────────────────────────────────────────────┐
│ Root Translation (3D or 6D)   [3/6]   ──→ Root position       │
│ 22 Joint Rotations (132D)     [132]   ──→ 22×6D rot vectors   │
│ ────────────────────────────────────                           │
│ TOTAL: 138D (or 141D with abs+rel translation)                │
│                                                                  │
│ Missing: Joint positions, velocity, foot contact              │
│ Impact: Cannot directly control xyz trajectory                │
│ Workaround: Would need to add position dims + FK loss        │
│ Effort: Medium (2 weeks + retrain)                            │
└────────────────────────────────────────────────────────────────┘
