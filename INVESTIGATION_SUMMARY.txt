ROOT CAUSE ANALYSIS:
  
  PRIMARY ISSUE: Overdamped PD control (ζ = 2.0)
  └─ 2× slower joint response than critically damped
  └─ At 50Hz control (20ms cycles), no time for disturbance recovery
  └─ Falls cascade when robot can't catch itself during transitions

CURRENT CONFIGURATION:

Physics Simulation:
  • Timestep: 0.001s (1000 Hz) ✓ GOOD
  • Control decimation: 20× → 50 Hz ✓ APPROPRIATE  
  • Control mode: Implicit PD ✓ CORRECT
  • Solver: MuJoCo built-in ✓ REASONABLE
  
  Status: Physics engine tuned well, PROBLEM IS CONTROL GAINS

PD GAIN CALCULATION (from g1.py):
  Natural frequency: ωₙ = 10 Hz (62.83 rad/s)
  Damping ratio: ζ = 2.0 ← CRITICAL PROBLEM
  
  Stiffness: K = m_a × ωₙ²
  Damping: D = 2 × ζ × m_a × ωₙ

COMPUTED GAINS BY JOINT:

  Hip pitch/yaw:      K~400   D~130   Limit: 88Nm   (weak for heavy legs)
  Hip roll/knee:      K~995   D~321   Limit:139Nm   (adequate)
  Ankle:              K~290   D~94    Limit: 50Nm   (weak for plant)
  Waist roll/pitch:   K~290   D~94    Limit: 50Nm   (CRITICAL - insufficient!)
  Shoulder/elbow:     K~145   D~47    Limit: 25Nm   (weak by design)

SETTLING TIME ANALYSIS:

  Formula: t_s = 4 / (ζ × ωₙ)
  
  ζ = 1.0 (critical):   t_s = 101 ms  ≈ 5 control cycles
  ζ = 2.0 (current):    t_s = 203 ms  ≈ 10 control cycles (2× SLOWER!)
  
  Problem: 10 cycles to settle, but new disturbance arrives every cycle
           → Can't catch robot from falling

FIVE ROOT CAUSES:

1. OVERDAMPED CONTROL (ζ=2.0)
   • 2× slower response than critically damped
   • By 20ms, position still far from target
   • Torques hit limits before reaching target
   • Residual error cascades into falls

2. FRAME RATE MISMATCH (30Hz → 50Hz)
   • 1.67× upsampling with linear interpolation
   • Can cause overshoot at joint limits
   • Velocity discontinuities at frame boundaries
   • High-frequency noise folded into commands

3. INSUFFICIENT TORSO STIFFNESS
   • Waist needs ~165Nm to prevent 0.1m tip
   • Available: 290 Nm/rad × 0.3 rad = 87Nm (INSUFFICIENT!)
   • Can't maintain posture on slopes or dynamic motions
   • Weak torso → leg corrections ineffective

4. QUATERNION DISCONTINUITIES
   • FK ground correction modifies pelvis quaternion
   • Linear interpolation can create orientation jumps
   • Large changes → ankles/knees can't keep up
   • Overdamped system magnifies problem

5. WEAK GROUND CONTACT
   • Ground correction only fixes Z height (not contact quality)
   • Ankle stiffness insufficient to prevent sliding
   • Foot slipping under load during complex motions
   • No frame-by-frame adjustment
