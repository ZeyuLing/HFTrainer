KEY FINDINGS
================================================================================

CORE FUNCTION: get_robot_state_from_mujoco() [Lines 327-370]
  Extracts robot state from MuJoCo physics engine
  Returns: dof_pos, dof_vel, body_rot (xyzw), root_local_ang_vel

CRITICAL CONVERSIONS:
  1. Quaternion: wxyz (MuJoCo) → xyzw (ProtoMotions)
     Conversion: quat[[1, 2, 3, 0]]
     
  2. Body indexing: data.xquat[i+1] for body i (world at index 0)
     Code: body_rot_wxyz = data.xquat[1:]
     
  3. Angular velocity: Already body-local in data.qvel[3:6]
     ✗ Wrong: data.cvel[0, 0:3] (world-frame)
     ✓ Right: data.qvel[3:6] (body-local)

KEY CONCEPTS:
  • Anchor body (torso, index 16) vs Root (pelvis, index 0)
  • ONNX inputs require batch dimension [1, ...]
  • Post-processing: accel clamp → EMA filter
  • Physics: 4 substeps per control step (decimation=4)
  • Observations are position-invariant (no XYZ)

SILENT FAILURE MODES (Check these when debugging):
  1. Angular velocity frame mismatch
  2. Body index offset error
  3. Quaternion wxyz ↔ xyzw confusion
  4. Mixing root and anchor bodies
  5. Missing mj_forward() call after qpos update

MAIN DATA FLOW (50 Hz Control Loop)
================================================================================

Per control step:

  1. robot_state = get_robot_state_from_mujoco(model, data)
     └─ Extracts: dof_pos, dof_vel, body_rot, root_local_ang_vel

  2. future_refs = player.get_future_references(...)
     └─ 25 steps ahead, pre-interpolated

  3. onnx_inputs = build_onnx_inputs(robot_state, future_refs)
     └─ Adds batch dim, constructs semantic keys

  4. pd_targets = ort.run(session, onnx_inputs)
     └─ ONNX inference → PD position targets [29 DOFs]

  5. Apply post-processing:
     ├─ Acceleration clamp (limits 2nd derivative)
     └─ EMA filter (low-pass smoothing)

  6. data.ctrl[:] = pd_targets
     └─ Apply control

  7. mujoco.mj_step() × 4 (decimation=4)
     └─ Physics simulation

FILE STRUCTURE IN MUJOCO
================================================================================

mujoco.MjData members used:
  qpos[nq]      Generalized coordinates (joint angles + free joint)
  qvel[nv]      Generalized velocities (joint vels + free joint vel)
  xquat[nbody]  Body quaternions (wxyz format, FK-computed)
  ctrl[nmotor]  Control inputs (PD targets)

For G1:
  nq = 36 (7 free + 29 actuated)
  nv = 35 (6 free + 29 actuated)
  nbody = 34 (world + 33 actual)
  nmotor = 29

Key slices:
  qpos[0:3]     Root position (world frame)
  qpos[3:7]     Root quaternion (wxyz, world frame)
  qpos[7:]      Joint angles (29 DOFs)
  qvel[0:3]     Root angular velocity (body-local)
  qvel[3:6]     Root linear velocity (world frame)
  qvel[6:]      Joint angular velocities (29 DOFs)
  xquat[0]      World body (skip)
  xquat[1+i]    Body i rotation (wxyz, world frame)
