QUESTION ANSWERS:

(a) How ctxt_input enters:
    → Linear encoder → [optional text_refiner] → as K,V in joint attention
    → Double-stream blocks concatenate motion_q with text_q for joint attention
    → Motion queries can attend to text embeddings

(b) How vtxt_input enters:
    → MLPEncoder → combined with timestep → adapter
    → Adapter used ONLY for AdaLN modulation (shift, scale, gate)
    → NOT as cross-attention K,V,Q tokens
    → Broadcast to ALL transformer blocks

(c) Text refiner exists?
    → YES: SingleTokenRefiner
    → Optional (configurable)
    → Self-attention over text tokens only
    → Timestep-aware conditioning

(d) Separate projections?
    → YES: ctxt_encoder (Linear) vs vtxt_encoder (MLPEncoder)
    → Different architectures for different semantics
    → ctxt: preserves token structure; vtxt: global aggregation

(e) Attention collapse?
    → NO: Math is stable
    → Zero ctxt: motion self-attention continues
    → Zero vtxt: modulation becomes timestep-only
    → Softmax is numerically stable (no NaN/Inf issues)
    → Information flow degrades but never collapses
