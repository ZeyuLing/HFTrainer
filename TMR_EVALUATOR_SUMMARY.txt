================================================================================
                          HOW TMR WORKS (FLOW)
================================================================================

INPUT:
  • Motion files: [N, T, D] (N motions, T timesteps, D joints)
  • Text descriptions: [N,] (N text captions)

STEP 1: ENCODE
  • Text Encoder: Text → Text Embeddings [N, embedding_dim]
  • Motion Encoder: Motion → Motion Embeddings [N, embedding_dim]

STEP 2: NORMALIZE
  • L2 normalize both embedding sets
  • Ensures fair distance comparison

STEP 3: COMPUTE DISTANCE MATRIX
  • dist_mat = euclidean_distance(text_emb, motion_emb)
  • Shape: [N, N]

STEP 4: CALCULATE METRICS

  a) R-PRECISION (Text-to-Motion):
     For each text, find closest K motions
     R@K = (# where true motion in top-K) / N
     → Measures: Can model retrieve correct motion for text?

  b) R-PRECISION (Motion-to-Text):
     For each motion, find closest K texts
     R@K = (# where true text in top-K) / N
     → Measures: Can model retrieve correct text for motion?

  c) MULTI-MODAL DISTANCE (MM-Dist):
     Sum diagonal of dist_mat / N
     → Measures: Overall text-motion alignment gap

  d) DIVERSITY:
     Variance of embeddings across samples
     → Measures: How varied are generated motions/texts?

OUTPUT:
  Dictionary containing:
  {
    'r_precision_top_1': float,
    'r_precision_top_3': float,
    'm2t_r_precision_top_1': float,
    'm2t_r_precision_top_3': float,
    'mm_dist': float,
    'diversity': float,
    'diversity_text': float
  }

                        TECHNICAL DETAILS
================================================================================

EMBEDDING DIMENSIONS:
  • Motion Embedding: 256-512 dimensions (configurable)
  • Text Embedding: 256-512 dimensions (must match)
  • Normalized to unit sphere (L2 norm = 1)

DISTANCE METRIC:
  • Type: Euclidean distance
  • Why: Normalized embeddings → equivalent to cosine similarity
  • Computation: torch.cdist(text, motion, p=2)

BATCH PROCESSING:
  • Standard batch size: 256 samples
  • Allows evaluation of large datasets
  • Memory efficient on VRAM

REPRODUCIBILITY:
  • Uses fixed random seed for diversity computation
  • Results should be consistent across runs
  • Report mean ± std for multi-seed evaluation
