┃ STEP 3: CONVERT ROT6D → AXIS-ANGLE (6-dim → 3-dim)                         ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

  For each joint's 6-value rot6d:

  ┌─ Input: rot6d = [R00, R01, R10, R11, R20, R21]  (row-major)
  │
  ├─ Step 1: REORDER to column-major
  │  indices:  [0,2,4,1,3,5]
  │  result:   [R00, R20, R10, R01, R21, R11]  (column-major)
  │
  ├─ Step 2: COMPLETE 3×3 ROTATION MATRIX via Gram-Schmidt
  │  ┌                                    ┐
  │  │  R00  R01  R02  │                  │
  │  │  R10  R11  R12  │  ← computed      │
  │  │  R20  R21  R22  │                  │
  │  └                                    ┘
  │  (First two columns given, compute third via orthogonalization)
  │
  ├─ Step 3: CONVERT to AXIS-ANGLE
  │  ┌─────────────────────────────────────────┐
  │  │ Use scipy.spatial.transform.Rotation    │
  │  │ .from_matrix().as_rotvec()              │
  │  │                                         │
  │  │ 3×3 rotation matrix → 3-element vector  │
  │  │ Axis-angle: [rx, ry, rz]                │
  │  │ (rotation vector form)                  │
  │  └─────────────────────────────────────────┘
  │
  └─ Output: axis-angle = [rx, ry, rz]  (3 floats)
