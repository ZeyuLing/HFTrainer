===============================================================================
TECHNICAL SPECIFICATIONS
===============================================================================

Input Format (motion_135 NPZ):
  - Shape: (T, 135) where T = number of frames
  - Structure per frame:
    * [0:3] = translation (x, y, z)
    * [3:135] = 22 joints × 6 rot6d values (row-major)
  - Total per-frame: 135 values

Rotation Representation Conversion:
  - Input: rot6d (6-dimensional rotation representation, row-major)
  - Process:
    1. Reorder: [0,2,4,1,3,5] (row-major → column-major)
    2. Gram-Schmidt orthogonalization
    3. Build 3×3 rotation matrix
    4. scipy.spatial.transform.Rotation.from_matrix().as_rotvec()
  - Output: axis-angle (3 values per rotation)

Output Format (SMPL-H JSON):
  - SMPL type: SMPL-H (52 joints, 156-param poses)
  - Pose vector structure:
    * [0:3] = root orientation (axis-angle)
    * [3:66] = body joints (21 × 3 = 63 params)
    * [66:156] = hand joints (30 × 3 = 90 params, all zeros)
  - Total per-frame: 156 values

JSON Format Specifics:
  - Compact serialization: separators=(',', ':')
  - No unnecessary whitespace
  - Compatible with existing motion_annot_web viewers
